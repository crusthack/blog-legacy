# 배열(array)
```c++
// 정적 배열 선언 방법
char array[20] = { 'h', 'e', 'l', 'l', 'o', ',', ' ', 'w', 'o', 'r', 'l', 'd', '!', '!'};
int numbers[5] = { 1, 2, 3, 4, 5 };


// 동적 배열 선언 방법
int n; std::cin >> n;
char *d_array = new char[n];

// 배열 사용법
array[1] = 'c';         // 두번째 원소 접근
std::cout << array[2];  // 문자 출력 
std::cout << array;     // 문자열 출력
```
- 연속된 메모리 공간을 가지는 자료구조입니다. 여러개의 자료를 저장할 때 주로 사용합니다. 
- 저장하는 자료형 T에 대해 해당 자료형의 메모리 크기(sizeof(T)) * 배열 크기 n 만큼의 메모리 공간을 차지합니다. 
- 배열의 시작 주소 + sizeof(T) * n => n번째 자료의 시작 주소. 인덱스 기반으로 주소 계산을 통한 빠른 참조가 가능하다는 특징이 있습니다. 
- 인덱스 접근 시, 배열의 범위를 벗어난 인덱스 접근을 하지 않도록 주의해야 합니다. 

## 동적 배열(vector)
[\<vector\>](https://cppreference.com/w/cpp/container/vector.html)
- 컴파일 타임에 고정된 크기를 가지는 정적 배열 array에 반해,  
런타임 도중에 배열 크기가 가변적으로 변하는 배열을 동적 배열 vector라고 합니다.
- 배열 크기를 바꿀 시엔 새로 메모리 공간을 할당 받고서 기존 원소를 복사 이동 후 기존 배열 메모리를 해제하는 동작이 필요합니다.  
잦은 메모리 할당, 복사는 성능 저하를 유발하므로 처음 배열 할당시에 사용할 메모리 크기를 잘 설정하는 것이 중요합니다. 

```c++
// 배열 크기 부족시 동작
int* newArray = new int[array.size * 2 + 1];        // 새 배열 할당 (보통 기존 배열의 2배 크기로 할당)
std::copy(array, array + array.size, newArray); // 기존 원소 복사
delete[] array;     // 기존 배열 메모리 해제   

// std::vector<T> 기본 사용법
std::vector<int> vec;   // vector 선언
vec.reserve(n: int)     // 메모리 크기 할당
vec.push_back(n)        // 원소 삽입. 뒤로 들어감 공간이 부족하면 알아서 메모리 재할당이 이뤄짐
std::vector<int> vec1(n, a)     // 선언과 동시에 메모리 할당 + 원소 삽입. 
```

## 배열의 주요 속성과 연산
- `capacity` - 할당된 메모리 공간에 원소를 저장할 수 있는 최대 개수 => sizeof(vector) / sizeof(T)
- `size` - 현재 저장된, 유효한 원소 개수
- `삽입` - 배열의 맨 뒤에 원소를 하나 추가합니다. 할당된 메모리 공간이 부족할 경우 재할당 동작이 들어갑니다. 
 -`접근` - 특정 인덱스의 원소를 참조합니다. 배열 범위 밖의 인덱스를 참조하지 않도록 주의가 필요합니다. 
- `교환` - 배열 안의 두 요소를 서로 교체합니다. 주로 배열을 정렬할 때 사용합니다. 
- `삭제` - 배열의 특정 원소를 삭제합니다. 이후 뒤에 있는 원소들을 한 칸씩 앞으로 당겨주는 복사 이동이 필요합니다. 

## 배열 활용 방법
### 기본 활용
- 단순히 원소 n개를 저장하는 자료구조로 사용합니다. 배열을 순회하면서 각 원소를 사용합니다. 

### 정렬 - 배열 순서에 방향성 부여
- 배열의 각 원소들을 특정 순서에 따라 정렬합니다. (e.g. 정수 배열을 오름차순으로 정렬, 원소 순서에 시간 속성 부여 => 큐, 스택)
- 정렬된 배열을 활용하여 특정 값을 쉽게 찾을 수 있습니다. 

### 인덱스에 속성 부여
- 원소의 위치, 인덱스에 특정 속성을 부여하여 의미있는 원소가 있다는 키값으로 사용합니다. (e.g. 해시)
