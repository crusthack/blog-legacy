# 암호학 개요
- 암호화란, 정보를 보호하기 위해 원문을 변경하는 것. 추후에 다시 원문으로 복호화할 수 있어야 함. (복구가 불가능한 해시와는 다름)
- 디지털 세계에선 0과 1로 존재하는 정보 신호가 노출되므로 다른 사람이 바로 해석하지 못 하도록 암호화를 통해 정보를 전달해야 함.

# 1. 고전 암호(아날로그 암호)
- 컴퓨터 등장 이전 튜링머신 등장까지의 아날로그 암호 
- 알파벳을 치환하는 암호부터 해서 기계적인 세계대전까지의 튜링 암호까지를 고전 암호라 부름 
- 대표적인 두 암호 시저 암호와 비즈네르 암호, 그리고 세계대전에서 쓰인 로터 암호만 정리 

## 시저 암호(shift cipher) - 단일 문자 암호
- 모든 알파벳을 각 3개씩 미루는 형식으로 암호화한 덧셈 암호.
- 복호화시 3개씩 앞당기면 됨. 
- 총 25개의 경우의 수만 존재해서 쉽게 복호화할 수 있음.
- 단일 문자 암호: 개별 문자가 하나의 문자로 1:1 매핑 되는 암호. 경우의 수는 최대 26!
- 단, 분석 방법이 존재해 훨씬 쉽게 뚫림. (빈도수, 구조 반복 분석)

### 곱셈 암호
- 각 문자에 키 값으로 곱셈을 수행함으로써 암호화하는 방식. $1(b) * 3(key) = 3(d)$. 
- 복호화 시 해당 키의 역원으로 다시 곱해줌으로써 $p * k * K^{-1} mod 26 = p$가 되게 함.  
$3(d) * 9(key^{-1}) = 27 mod 26 = 1(b)$
- 26에 대한 곱셈의 역원 쌍이 12개밖에 존재하지 않음. 

### 아핀 암호(affine cipher)
- 곱셈 암호와 더셈 암호 복합적 사용. 키 여러개

### 단일 문자 암호의 한계
- 각 문자별 매핑 경우의 수에 따라 최대 경우의 수 26!
- 단, 각 문자가 고정적으로 변하므로 빈도수 분석에 취약함. 

## 비즈네르 암호(vigenere cipher) - 다중 문자 암호
- 암호 키로 단어를 사용해 암호화. 암호화/복호화 편하게 하기 위해 단어 매칭 되는 26*26 테이블 존재
- 빈도수 공격에 취약. 

### 플레이페어 암호(playfair cipher)
- 5*5 격자판에 26개 문자 삽입(I와J는 같은 칸). 문장에서 문자를 2개씩 뽑아서 둘을 연관지어 암호화  
**암호화 규칙**
1. 두 문자가 격자의 같은 행에 속한다면 격자에서 각 문자의 우측에 있는 문자로 치환
2. 두 문자가 격자의 같은 열에 속한다면 격자에서 각 문자의 하단에 있는 문자로 치환
3. 두 문자가 같은 행, 열에 속하지 않는다면 각 문자는 자신의 행에서 다른 문자의 열에 대응되는 문자로 치환
- 빈도수 문제 및 구조적 약점 존재

### 철도 울타리 암호(Rail Fence cipher) 열 전치 암호(Row Transposition Ciphers)
- 보만다지진처럼 암호화. 쉽게 뚫림
- 문장을 테이블로 적고서 임의의 열을 연속적으로 적음. 

## 로터 암호 - 에니그마
- 물리적 기계장치를 통한 암호화
- 기존에 A가 B로 매핑되어 있다면, 해당 문자 암호화 시 로터가 돌아가 A가 다른 C 혹은 D로 자동으로 매핑이 바뀌게 됨. 
- 매핑이 바뀌는 방식은 각 입력 문자에 따라, 초기 매핑에 따라 달라지기 때문에 규칙성을 찾기가 힘들게 됨. 
- 로터 기계의 동작은 초기 설정에 따라 규칙적이지만 치환 규칙이 매 입력마다 달라지게 되어 복호화 하기가 힘듦.
- 기계 초기 설정(키)을 매일 마다 새롭게 배포함으로 기밀성을 가져감. 이는 대칭키 시스템과 비슷.

# 3. 난수
- 특정한 배열 순서나 규칙을 가지지 않는 연속적인 임의의 수
- **균일 분포**: 수열의 비트 분포가 균일 해야 함. 0과 1의 출현 빈도
- **독립성(비예측성)**: 수열에 예측성이 존재하면 안 됨. 무규칙성
##### 의사 난수(pseudo random number)
- 컴퓨터(디지털 시스템)에 의해서 만들어지는 랜덤 값. 

## TRNG(True Random Number Generator)
- 현실의 아날로그 값을 이용해 실질적으로 랜덤한 소스를 입력으로 사용
- 펄스 탐지기, 누전 축전기 혹은 열잡음, 음향/영상 입력이나 디스크 탐색 회전 속도 같은 아날로그 값을 측정해 사용함. 
### 편향 보정 기법(deskewing)
- 환경에 따라 값이 0또는 1쪽으로 편향될 수 있음. 이를 **편향(Skew)**이라고 함
- 0과 1의 빈도수를 비슷하게 맞추기 위해 해시 함수를 사용할 수 있음. (SHA-1)

## PRNG(Pseudo Random Number Generator)
- 시드값 기반 결정적 랜덤 비트열 생성. 시드는 난수 혹은 의사난수여야 함.(난수 권고)
- **임의성**과 **비예측성**을 갖춰야 함. 
##### 임의성(Randomness)
- 0과 1이 균일하게 나와야 됨
- 어떤 부분 비트열에 대해서도 랜덤성이 유지되어야 함.
- 시드값이 같으면 출력 비트열도 동일해야 함

##### 비예측성(Unpredictability)
- 수열이 분석 불가능, 예측 불가능 해야 함. 

## PRF(Pseudo Random Function)
- 시드값과 특정 값을 같이 입력해 고정된 하나의 값을 생성

# 4. 대칭키 암호
- 암호화와 복호화를 같은 키를 사용하는 방식
- 반대의 비대칭 키 암호는 수학적 연산을 통해 암호화-복호화 하는 키가 서로 다름. 
- 대칭 키 방식이 비대칭 키 방식보다 단순하므로, 수학적으로 연산이 빠르지만 키를 어떻게 전달하느냐의 문제가 있음. 

## 스트림 암호(Stream Ciphers)
- 비트, 혹은 바이트 단위로 암호화. 연속적인 순서가 존재. 
- 블록 암호보다 연산이 단순하고(XOR 연산) 키 스트림을 미리 생성해둘 수 있으며 즉시 즉시 복호화가 가능하다는 이점이 있음.

### 키 스트림
- 키 스트림: 암호화/복호화 하는 데에 사용하기 위한 연속적인 키 값. 동적으로 생성하여 사용. 
- 동기 방식: 키값만을 가지고 키 스트림을 생성
- 비동기 방식: 키 값과 암호문을 둘 다 활용하여 키 스트림 생성

### LFSR(Linear Feedback Shift Register)
- 키 값들을 xor 방식을 통해 다음 키 값을 구함.  (e.g. $x_{n+3} = x_{n+1} \oplus x_n$)
- 키 길이 n에 따라 하나의 키열 길이 => $2^n -1$
- 길이 n과 각 계수(이전 항 활요 여부) c_n 존재
- 선형적(예측 가능)이라 취약성 있는 방법
- Trivium과 GSM에서 사용(통신 기술)

#### LFSR 공격
- 평문과 암호문을 알고 있다는 가정 하에, 둘을 xor 연산해서 키 스트림을 알아냄.
- 키 길이 n을 가정하면서 LFSR 방정식을 찾아냄
- $$X_{n+m} = C_0X_n \oplus C_1X_{n+1} \oplus ... \oplus C_{m-1}X_{n+m-1}$$ 라는 공식을 활용.
- X는 알려져있는 키 스트림이며, n에 따른 C_n이라는 계수값의 0/1 여부를 알아내야 함.

## 블록 암호(Block Ciphers)
- 데이터를 블록 단위(64bit, 128bit)로 암호화. 연산이 복잡하고 데이터를 모아서 즉석으로 일괄 연산 해야돼서 속도가 느림. 
- Substitution - 치환. S-Box라는 치환 도구에 입력 블록을 넣고서 암호문으로 출력. 비선형적으로 동작(예측 불가능)
- Permutation - 확산. P-Box라는 재배치 도구를 통해 비트들의 순서를 뒤섞음. 
- 위의 S-P 네트워크를 혼돈과 확산이라고 부름. 

## DES(Data Encryption Standard)
- 블록 크기는 64비트, key 길이 $2^{56}$. 나머지 8개 비트는 패딩
### Feistel Cipher Structure
- 블록 하나를 반으로 나눈 뒤 서로 흔드는 암호 구조. DES에 사용
- **Feistel 구조의 특징:**
  - 64비트 입력을 왼쪽 32비트($L_0$)와 오른쪽 32비트($R_0$)로 반으로 쪼갭니다.
  - $R_0$는 라운드 함수 $f$에 들어갑니다. 이 함수 안에서 48비트 서브키($K_1$)와 혼합됩니다.
  - 함수 $f$를 통과해 나온 32비트 결과값을 $L_0$와 XOR 합니다. 이 결과가 다음 라운드의 오른쪽($R_1$)이 되고, 기존의 오른쪽($R_0$)은 그대로 다음 라운드의 왼쪽($L_1$)으로 넘어갑니다. ($L_1 = R_0$, $R_1 = L_0 \oplus f(R_0, K_1)$)
  - 이 과정을 16라운드 동안 반복합니다.
  - **가장 큰 장점:** 암호화 과정과 복호화 과정의 **알고리즘 구조가 100% 동일**합니다. 복호화할 때는 암호문을 입력으로 넣고 서브키를 반대 순서($K_{16}, K_{15} \dots K_1$)로 넣어주기만 하면 평문이 나옵니다.
- **라운드 함수 $f$의 내부:**
  1. **Expansion (확장):** 32비트 입력을 48비트로 뻥튀기하며 섞어줍니다.
  2. **Key Mixing:** 48비트 서브키와 XOR 합니다.
  3. **Substitution (S-box):** 48비트를 6비트씩 8개로 쪼개어, 각각을 비선형 표(S-box)를 참조해 4비트로 바꿉니다. 결과적으로 다시 32비트로 줄어듭니다. (DES의 유일한 비선형 요소이자 혼돈의 핵심).
  4. **Permutation (전치):** 32비트의 위치를 P-box에 따라 섞습니다 (확산).
- **취약점:** DES 알고리즘 자체는 차분 분석(Differential Cryptanalysis, Biham과 Shamir) 등에 잘 견디도록 설계되었으나, 가장 큰 문제는 **56비트라는 너무 짧은 키 길이**였습니다. 1990년대 후반 EFF의 'Deep Crack' 머신 등에 의해 이틀 만에 전수 조사로 뚫리게 되면서 폐기 수순을 밟았습니다.

## AES(Advanced Encryption Standard)
- DES의 개선형 
- 블록 단위 128비트(16바이트), 키 128, 192, 256 비트 단위 (키에 따른 라운드 10, 12, 14) 
- 128비트의 블록을 8비트 단위 16개 블록으로 나눈 후 행렬 연산
- 라운드 과정과, 키 익스팬션, sbox, 복호화
- 각 라운드
1. ByteSub: Byte-by-byte substitution
2. ShiftRow: Byte-by-byte permutation
3. MixColumn: substitution using arithmetic over GF
4. AddRoundKey: xor

## 운영 모드
### ECB(Electronic Codebook)
- 각 블록을 독립적으로, 동일한 키를 사용하여 암호화

### CBC(Cipher Block Chaining)
- 이전 단계의 암호문 블록을 다음 단계의 평문과 XOR한 후 암호화
- 처음 블록에 xor을 위해 초기화 벡터(IV) 필요
- 병렬 암호화 불가능. 느림. 

### CFB(Cipher FeedBack)
- 이전 블록 암호문을 다음 블록 암호문에 사용
- 병렬 연산 불가능

### OFB(Output FeedBack)
- CFB에서 마지막에 xor 이전의 암호문을 다음 암호문에 사용

### CTR(Counter)
- 각 블록마다 1씩 증가하는 카운터 값을 암호화하여 키 스트림을 생성합니다.
- 병렬 연산 가능
- 평문을 암호화에 바로 사용하는게 아니라, 카운터값을 키값을 이용해 암호화한 값을 평문에 xor한 후 암호문으로 사용

### GCM(Galois Counter Mode)

## RSA
- 정수 인수분해 문제(Integer factorization problem) 기반 
- 두 개의 소수 p, q가 있을 때. 
- n = p * q, pi = (p-1) * (q-1)
- e는 1 \< e \< pi 이면서, pi와 서로소인 수들 중 하나 
- d는 d * e mod pi = 1이며 pi보다 작은 값 
- => 공개키는 (e, n). 비밀키는 d.
- (e, n) 쌍을 공개하며, (d, n)쌍을 개인키로 저장. 혹은 (p, q, d)을 저장 

## ECC(타원 곡선 암호)

- 통상적으로 사용하는 실수상의 타원곡선항: $$y^2 = x^3 + ax + b$$
- 타원곡선이 만족해야하는 판별식 $$4a^3 + 27b^3 {\neq} 0$$
- ECC의 수학적 특성
- 소수 곡선, 이진 곡선 
- ECDH, ECDSA, ECIES
