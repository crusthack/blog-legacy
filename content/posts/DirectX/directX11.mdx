# DirectX SDK 설치시 에러 

## s1023 에러
```terminal
MsiExec.exe /passive /X{F0C3E5D1-1ADE-321E-8167-68EF0DE699A5}
MsiExec.exe /passive /X{1D8E6291-B0D5-35EC-8441-6616F567A0F7}
```
- [재배포 패키지 제거](https://learn.microsoft.com/ko-kr/previous-versions/troubleshoot/windows/win32/s1023-error-when-you-install-directx-sdk)

## 프로젝트 설정 
- 쉐이더 파일에 Property(속성) 들어가서 HLSL Compiler entrypoint name VS로 수정
- 프로젝트 설정, VC++ Directories에서 
- include directory에 `$(DXSDK_DIR)Include;$(IncludePath)`추가
- library directory에 `$(DXSDK_DIR)Lib\x64;$(LibraryPath)`추가
