# 기본 사용 
```terminal 
git clone <repo>
git add .
git commit -a -m <commit_name>
git push 
```

## remote 추가 
```terminal 
git remote add <repo>
git branch -M main 
git push
```

## 추가된 파일 제거 
`git rm --cached <파일명>`
`git rm -r --cached .`
