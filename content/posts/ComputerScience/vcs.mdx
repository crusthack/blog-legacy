# git 버전 관리 시스템 
- 파일 상태: untracked - unmodified - modified - staged
- 추적 안 되는 파일(추가가 안 됐거나 gitignore로 제외 된)은 untracked
- add 명령어를 사용하면 파일이 staged 상태가 됨. 
- commit을 통해 staged된 파일들의 상태, 버전을 저장. unmodified가 됨. 
- unmodified 파일을 수정하면 modified가 됨. 해당 파일을 add 하면 staged로 올라감 

# 기본 사용 
```terminal 
git clone <repo>
git add .
git commit -a -m <commit_name>
git push 
```

## remote 추가 
```terminal 
git remote add <repo>
git branch -M main 
git push
```

## 추가된 파일 제거 
`git rm --cached <파일명>`
`git rm -r --cached .`
