# Input System

## SlateApplication
- SlateApplication은 언리얼 게임의 입력을 전체적으로 관리하는 최상위 클래스입니다. 
- OS로부터 받아온 사용자 입력은 FKeyEvent(키보드, 패드 입력), FPointerEvent(마우스, 터치 입력)으로 분류돼 여기에서 UI들에 라우팅을 통해 전달합니다. 
- SlateApplication이 UI를 계층적으로 입력을 전달하고, 게임 컨트롤러에게의 입력 전달 또한 SViewport라는 위젯을 통해 UGameViewportClient -> PlayerController로 입력을 전달합니다.

### FKeyEvent
- KeyEvent는 키보드나 게임 패드 입력 같은 물리적 버튼 입력을 처리합니다. 
- KeyEvent는 현재 SlateApplication이 Focus하고 있는 대상을 기점으로 터널링(최상위 계층부터 포커스된 객체까지)과 버블링(포커스된 객체부터 최상위 계층)을 통해 입력을 전달합니다.
- 터널링 과정에서는 UI가 Preview 이벤트를 수행하고, 버블링 과정에서는 UI가 정식 일반 이벤트를 수행합니다. 
- 만약에, 라우팅 과정에서 특정 위젯(UI)가 입력을 소비하고서 FReply::Handled()를 반환한다면 이후 전달을 그만두고 입력 처리를 마무리합니다. 
- 즉, focus를 UI에 둔다면 해당 UI가 입력을 처리하고, viewport에 둔다면 PlayerController가 입력을 처리합니다. 
- 만약에 특정 UI가 입력을 소비했음에도 다른 UI들이 받아서 처리하게하려면, `FReply::UnHandled()`를 반환하도록 하면 됩니다. 

#### Focus 변경하는 주요 메서드
- `bool SetUserFocus(int32 UserIndex, const TSharedPtr<SWidget>& Widget, EFocusCause Cause)`: 특정 UI에 focus 두기
- `bool FSlateApplication::SetKeyboardFocus(const TSharedPtr< SWidget >& OptionalWidgetToFocus, EFocusCause ReasonFocusIsChanging)`: 특정 UI에 키보드 focus 두기  
 내부적으로 SetUserFocus를 사용해 키보드 포커스를 해당 위젯에 둡니다.
- `void FSlateApplication::SetAllUserFocusToGameViewport(EFocusCause ReasonFocusIsChanging)`: viewport에 focus 둬서 PlayerController이 입력 받도록 하기

#### FSlateApplication::ProcessKeyDownEvent
```c++
// UnrealEngine\Engine\Source\Runtime\Slate\Private\Framework\Application\SlateApplication.cpp

bool FSlateApplication::ProcessKeyDownEvent( const FKeyEvent& InKeyEvent )
{
	SCOPE_CYCLE_COUNTER(STAT_ProcessKeyDown);

	TScopeCounter<int32> BeginInput(ProcessingInput);

	TSharedRef<FSlateUser> SlateUser = GetOrCreateUser(InKeyEvent);

	// Analog cursor gets first chance at the input
	if (InputPreProcessors.HandleKeyDownEvent(*this, InKeyEvent))
	{
		return true;
	}

	FReply Reply = FReply::Unhandled();
	SetLastUserInteractionTime(this->GetCurrentTime());
	
	if (SlateUser->IsDragDropping() && InKeyEvent.GetKey() == EKeys::Escape)
	{
		// Pressing ESC while drag and dropping terminates the drag drop.
		SlateUser->CancelDragDrop();
		Reply = FReply::Handled();
	}
	else
	{
		LastUserInteractionTimeForThrottling = LastUserInteractionTime;

		// Bubble the keyboard event
		TSharedRef<FWidgetPath> EventPathRef = SlateUser->GetFocusPath();
		const FWidgetPath& EventPath = EventPathRef.Get();

		// Switch worlds for widgets in the current path
		FScopedSwitchWorldHack SwitchWorld(EventPath);

		// Tunnel the keyboard event
		Reply = FEventRouter::RouteAlongFocusPath(this, FEventRouter::FTunnelPolicy(EventPath), InKeyEvent, [] (const FArrangedWidget& CurrentWidget, const FKeyEvent& Event)
		{
			if (CurrentWidget.Widget->IsEnabled())
			{
				const FReply TempReply = CurrentWidget.Widget->OnPreviewKeyDown(CurrentWidget.Geometry, Event);

				return TempReply;
			}
			return FReply::Unhandled();
		}, ESlateDebuggingInputEvent::PreviewKeyDown);

		// Send out key down events.
		if ( !Reply.IsEventHandled() )
		{
			Reply = FEventRouter::RouteAlongFocusPath(this, FEventRouter::FBubblePolicy(EventPath), InKeyEvent, [] (const FArrangedWidget& SomeWidgetGettingEvent, const FKeyEvent& Event)
			{
				if (SomeWidgetGettingEvent.Widget->IsEnabled())
				{
					const FReply TempReply = SomeWidgetGettingEvent.Widget->OnKeyDown(SomeWidgetGettingEvent.Geometry, Event);

					return TempReply;
				}

				return FReply::Unhandled();
			}, ESlateDebuggingInputEvent::KeyDown);
		}

		// If the key event was not processed by any widget...
		if ( !Reply.IsEventHandled() && UnhandledKeyDownEventHandler.IsBound() )
		{
			Reply = UnhandledKeyDownEventHandler.Execute(InKeyEvent);
		}
	}

	return Reply.IsEventHandled();
}
```


### FPointerEvent
- PointerEvent는 마우스 입력이나 화면 터치와 같은 특정 포인트 입력을 처리합니다.
- 포인터 이벤트는 화면에 입력을 준 특정 포인트를 기점으로 Hit Test를 진행하여 해당 지점에 있는 UI 계층을 capture한 뒤 해당 UI 경로에 라우팅을 수행합니다. 
- 이 또한 앞선 위젯을 뚫고서 뒤의 위젯에 이벤트를 전달하고 싶으면 `FReply::UnHandled()`를 반환하도록 하면 됩니다.

#### FInputModeGameOnly
```c++
void FInputModeGameOnly::ApplyInputMode(FReply& SlateOperations, class UGameViewportClient& GameViewportClient) const
{
	TSharedPtr<SViewport> ViewportWidget = GameViewportClient.GetGameViewportWidget();
	if (ViewportWidget.IsValid())
	{
		TSharedRef<SViewport> ViewportWidgetRef = ViewportWidget.ToSharedRef();
		SlateOperations.UseHighPrecisionMouseMovement(ViewportWidgetRef);
		SlateOperations.SetUserFocus(ViewportWidgetRef);
		SlateOperations.LockMouseToWidget(ViewportWidgetRef);
		GameViewportClient.SetMouseLockMode(EMouseLockMode::LockOnCapture);
		GameViewportClient.SetIgnoreInput(false);
		GameViewportClient.SetMouseCaptureMode(bConsumeCaptureMouseDown ? EMouseCaptureMode::CapturePermanently : EMouseCaptureMode::CapturePermanently_IncludingInitialMouseDown);
	}
}
```

#### FInputModeUIOnly
```c++
void FInputModeUIOnly::ApplyInputMode(FReply& SlateOperations, class UGameViewportClient& GameViewportClient) const
{
	TSharedPtr<SViewport> ViewportWidget = GameViewportClient.GetGameViewportWidget();
	if (ViewportWidget.IsValid())
	{
		const bool bLockMouseToViewport = MouseLockMode == EMouseLockMode::LockAlways
												 || (MouseLockMode == EMouseLockMode::LockInFullscreen && GameViewportClient.IsExclusiveFullscreenViewport());
		SetFocusAndLocking(SlateOperations, WidgetToFocus, bLockMouseToViewport, ViewportWidget.ToSharedRef());

		SlateOperations.ReleaseMouseCapture();

		GameViewportClient.SetMouseLockMode(MouseLockMode);
		GameViewportClient.SetIgnoreInput(true);
		GameViewportClient.SetMouseCaptureMode(EMouseCaptureMode::NoCapture);
	}
}
```

#### FInputModeGameAndUI
```c++
void FInputModeGameAndUI::ApplyInputMode(FReply& SlateOperations, class UGameViewportClient& GameViewportClient) const
{
	TSharedPtr<SViewport> ViewportWidget = GameViewportClient.GetGameViewportWidget();
	if (ViewportWidget.IsValid())
	{
		const bool bLockMouseToViewport = MouseLockMode == EMouseLockMode::LockAlways
			|| (MouseLockMode == EMouseLockMode::LockInFullscreen && GameViewportClient.IsExclusiveFullscreenViewport());
		SetFocusAndLocking(SlateOperations, WidgetToFocus, bLockMouseToViewport, ViewportWidget.ToSharedRef());

		SlateOperations.ReleaseMouseCapture();

		GameViewportClient.SetMouseLockMode(MouseLockMode);
		GameViewportClient.SetIgnoreInput(false);
		GameViewportClient.SetHideCursorDuringCapture(bHideCursorDuringCapture);
		GameViewportClient.SetMouseCaptureMode(EMouseCaptureMode::CaptureDuringMouseDown);
	}
}
```

## Enhanced Input System
- Unreal Engine 5에 새로 도입된 입력 처리 방식입니다. 
 - 기존 Legacy Input에서는 키 입력을 받으면 하나의 게임 전체 매핑에 따라 바인딩된 함수를 즉각적으로 호출하는 구조였습니다.
  매핑이 단조로워지고 입력을 관리하기 힘들며 호출된 함수측에서 입력의 상태를 판단해야 하는 단점이 있었습니다.
- 향상된 입력은 입력 처리 과정에서 중간 파이프라인을 추가해 여러개의 매핑 구조를 사용할 수 있게 하고, 인풋시스템 자체에서 입력 상태를 판단하여 일관성있는 함수 작성을 할 수 있게 도와줍니다.
- 향상된 입력은 **Input Mapping Context**와 **Input Action** 2가지 요소를 사용해 입력을 처리합니다.
- **PlayerController가 possess한 pawn이 Input System을 먹습니다**

### 기본 사용

#### Input Mapping Context 설정
![IMC 기본](IMC_Default.JPG)
- wasd 매핑을 추가해줍니다. MoveAction는 2D vector값을 사용하고 전진과 후진에 사용할 값을 벡터 Y값으로, 좌우이동에는 X값으로 사용할 것입니다.
- 기본적으로 입력이 트리거될 때 인풋 값이 3D vector (x, y, z) => (1, 0, 0) 으로 들어옵니다.
 전진과 후진에 사용할 값을 Y값으로 수정하기 위해 Value Swizzle변환자를 추가하고서 Order를 YXZ로 설정합니다.
  그럼 w 입력시에 (y, x, z) => (1, 0, 0)으로 매핑돼서 y값이 1이 됩니다. 
- 후방 이동과 좌측 이동에는 음수값을 사용할 것입니다. 이를 위해 negate를 붙여줘 (1, 0, 0)으로 들어온 값을 (-1, 0, 0)이 되게 합니다.

#### Character Actor에서 Input Action 사용
```c++
void AMyCharacter::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
	Super::SetupPlayerInputComponent(PlayerInputComponent);

	if (UEnhancedInputComponent* EnhancedInputComponent = Cast<UEnhancedInputComponent>(PlayerInputComponent))
	{
		EnhancedInputComponent->BindAction(MoveAction, ETriggerEvent::Triggered, this, &AMyCharacter::Move);
		EnhancedInputComponent->BindAction(LookAction, ETriggerEvent::Triggered, this, &AMyCharacter::Look);

	}
}

void AMyCharacter::Move(const FInputActionValue& Value)
{
	FVector2D MovementVector = Value.Get<FVector2D>();
	AddMovementInput(GetActorForwardVector(), MovementVector.Y);
	AddMovementInput(GetActorRightVector(), MovementVector.X);
}
```

### Input Action
- 입력의 상태를 정의하고 콜백함수를 연결하는 클래스입니다. 
- Input Action의 트리거 이벤트는 트리거 조건들에 의해 **Triggered**, **Started**, **Ongoing**, **Completed**, **Canceled** 5가지 이벤트가 호출됩니다. 
- `None`: 아무런 트리거 조건이 달성되지 않음.
- `Started`: 트리거 조건을 평가하기 시작한 상태. 트리거 조건을 일부 만족함. (e.g. 2번 탭(터치) 하는 트리거가 있을 경우 첫 번째 탭 시)
- `Ongoing`: 트리거 조건을 일부 만족한 상태. 매 프레임마다 Ongoing 이벤트가 호출됨.
- `Triggered`: 트리거 조건이 모두 성립이 된 상태. 매 프레임마다 Triggered 이벤트가 호출됨.
- `Completed`: 트리거 조건을 모두 만족한 상태로 입력이 종료됨. 
- `Canceled`: 트리거 조건이 충족되지 않은 상태에서 입력이 종료됨.

### Trigger
- IMC와 IA를 이루는 트리거 조건입니다. 트리거들의 종류와 상태에 따라 IMC, IA의 트리거 이벤트 또한 결정됩니다. 

#### Trigger State
- Trigger의 상태는 `None`, `Ongoing`, `Triggered` 세 단계로 분류됩니다. 
- `None`: 입력 없음
- `Ongoing`: 조건이 일부 충족됨
- `Triggered`: 조건이 충족됨

#### Trigger Type
- Trigger의 종류는 `Explicit`, `Implicit`, `Blocker` 세 가지가 있습니다.
- `Explicit`: 트리거들 중에 **Explicit**인 트리거 하나만 충족되어도 **Explicit** 타입 트리거가 해당 트리거의 상태를 따라감
- `Implicit`: 해당 타입을 가진 모든 트리거들의 상태를 따라감 
- `Blocker`: 해당 타입을 가진 트리거 하나만 발동되어도 이벤트 상태 전체가 None으로 블록 됨

<br/>

- 트리거가 아무것도 없는 경우: 입력이 들어오면 바로 IA의 상태가 Triggered로 전환됨. 
- Explicit 트리거가 있는 경우: Explicit 타입 트리거들 중 최고 단계의 상태가 됨. 하나만 Triggered 이여도 IA가 Triggered로. 하나만 Ongoing 이고 나머지가 None이면 Ongoing
- Implicit 트리거가 있는 경우: 모든 Implicit 트리거들의 최저 단계가 됨. and 연산과 비슷함.
- Blocker 트리거가 있는 경우: 하나의 Blocker 트리거만 발동되면 IA의 상태가 None이 됨.

#### IA의 상태 전이
- 위의 Trigger Type 연산에 의해 Trigger를 총합한 IA의 Triggers는 3가지 상태를 가짐 `None`, `Ongoing`, `Triggered`
- 이에 의해 IA는 트리거 이벤트는 다음과 같이 호출됨. (Ongoing과 Triggered는 매 프레임마다 호출)
None -> Started -> Ongoing -> Triggered -> Completed (Triggers가 바로 Triggered가 되면 Ongoing은 생략)  
None -> Started -> Ongoing -> Canceled

#### 기본 Trigger
- 모든 Trigger들은 UInputTrigger을 상속받음. UInputTrigger는 기본적으로 Explicit 타입을 가짐.
![Triggers](Triggers.JPG)

| Trigger Name         | Trigger Type | 트리거 동작 설명                                                                                       |
| -------------------- | ------------ | ----------------------------------------------------------------------------------------------- |
| **Down**             | Explicit     | 입력 값이 ActuationThreshold를 **넘는 동안 계속 Triggered** 상태. 트리거가 하나도 없을 때의 **기본 동작**                   |
| **Pressed**          | Explicit     | 입력 값이 Threshold를 **처음 넘는 순간 한 번만 Triggered**. 유지해도 추가 Trigger 없음                                |
| **Released**         | Explicit     | 입력이 Threshold 이상으로 유지되다가 **Threshold 아래로 떨어지는 순간 Triggered**                                    |
| **Hold**             | Explicit     | 입력이 Threshold 이상으로 **HoldTimeThreshold 시간 이상 유지되면 Triggered**<br/>옵션에 따라 1회 또는 매 프레임 Trigger 가능 |
| **Hold And Release** | Explicit     | Threshold 이상으로 **지정 시간 이상 유지 후, 놓았을 때 Triggered**                                               |
| **Tap**              | Explicit     | Threshold 이상으로 눌렀다가 **TapReleaseTimeThreshold 시간 안에 놓으면 Triggered**                             |
| **Repeated Tap**     | Explicit     | 지정 시간 내 **여러 번 탭**했을 때 Triggered (예: 더블 탭)                                                      |
| **Pulse**            | Explicit     | 입력이 유지되는 동안 **Interval 주기마다 Triggered**                                                         |
| **Chorded Action**   | **Implicit** | 다른 Input Action이 **Triggered 상태일 때만** 이 Action이 Trigger 가능                                      |
| **Chord Blocker**    | **Blocker**  | Chord 조건이 만족되면 **다른 입력을 차단** (자동 생성, 수동 추가 금지)                                                  |
| **Combo (Beta)**     | **Implicit** | 여러 Input Action을 **순서대로 완료**했을 때 Triggered                                                      |


### Modifier
- 입력 값을 수정합니다. (e.g. 키보드 입력시 (x, y, z) 벡터 값이 (1, 0, 0)으로 입력되는데 swizzle을 통해 XYZ 순서를 YXZ로 바꾸면서 Y값이 1이 되게 할 수 있습니다.)

```c++
    /**
    * Trigger states are a light weight interpretation of the provided input values used in trigger UpdateState responses.
    */
    UENUM()
    enum class ETriggerState : uint8
    {
        // No inputs
        None,

        // Triggering is being monitored, but not yet been confirmed (e.g. a time based trigger that requires the trigger state to be maintained over several frames)
        Ongoing,

        // The trigger state has been met
        Triggered,
    };

    /**
    * Trigger events are the Action's interpretation of all Trigger State transitions that occurred for the action in the last tick
    */
    UENUM(BlueprintType, meta = (Bitflags, UseEnumValuesAsMaskValuesInEditor = "true"))
    enum class ETriggerEvent : uint8
    {
        // No significant trigger state changes occurred and there are no active device inputs
        None		= (0x0)		UMETA(Hidden),
        // Triggering occurred after one or more processing ticks
        Triggered	= (1 << 0),	// ETriggerState (None -> Triggered, Ongoing -> Triggered, Triggered -> Triggered)
        
        // An event has occurred that has begun Trigger evaluation. Note: Triggered may also occur this frame, but this event will always be fired first.
        Started		= (1 << 1),	// ETriggerState (None -> Ongoing, None -> Triggered)

        // Triggering is still being processed. For example, an action with a "Press and Hold" trigger
        // will be "Ongoing" while the user is holding down the key but the time threshold has not been met yet. 
        Ongoing		= (1 << 2),	// ETriggerState (Ongoing -> Ongoing)

        // Triggering has been canceled. For example,  the user has let go of a key before the "Press and Hold" time threshold.
        // The action has started to be evaluated, but never completed. 
        Canceled	= (1 << 3),	// ETriggerState (Ongoing -> None)

        // The trigger state has transitioned from Triggered to None this frame, i.e. Triggering has finished.
        // Note: Using this event restricts you to one set of triggers for Started/Completed events. You may prefer two actions, each with its own trigger rules.
        // Completed will not fire if any trigger reports Ongoing on the same frame, but both should fire. e.g. Tick 2 of Hold (= Ongoing) + Pressed (= None) combo will raise Ongoing event only.
        Completed	= (1 << 4),	// ETriggerState (Triggered -> None)
    };
    ENUM_CLASS_FLAGS(ETriggerEvent)

    namespace UE::Input
    {
        // Returns an FString that represents the given ETriggerEvent
        ENHANCEDINPUT_API FString LexToString(const ETriggerEvent TriggerEvent);
    };

    /**
    * Trigger type determine how the trigger contributes to an action's overall trigger event the behavior of the trigger
    */
    UENUM()
    enum class ETriggerType : uint8
    {
        // Input may trigger if any explicit trigger is triggered.
        Explicit,

        // Input may trigger only if all implicit triggers are triggered.
        Implicit,

        // Inverted trigger that will block all other triggers when IsBlocking returns true
        Blocker
    };

    /**
    * Represents what ETriggerEvent types can be triggered off of a give UInputTrigger.
    * Used to determine if a warning should be placed on a exec pin that would never get called
    * on a K2Node_EnhancedInputAction node
    */
    UENUM()
    enum class ETriggerEventsSupported : uint8
    {
        // This trigger supports no trigger events. 
        None				= (0x0),
        
        // This trigger supports just the Triggered event type. This include ETriggerEvent::Triggered
        Instant				= (1 << 0),

        // This trigger cannot be canceled, once it is started it cannot be stopped from being triggered
        // This includes the ETriggerEvents of Started, Ongoing, and Triggered 
        Uninterruptible		= (1 << 1),

        // This represents a trigger than can be held down and have a duration, and be canceled. This includes
        // the ETriggerEvents of Started, Ongoing, Canceled, and Triggered. 
        Ongoing				= (1 << 2),

        // This trigger supports all trigger events
        All					= (Instant | Uninterruptible | Ongoing), 
    };
    ENUM_CLASS_FLAGS(ETriggerEventsSupported)

    /**
    Base class for building triggers.
    Transitions to Triggered state once the input meets or exceeds the actuation threshold.
    */
    UCLASS(MinimalAPI, Abstract, Blueprintable, EditInlineNew, CollapseCategories, Config = Input, defaultconfig, configdonotcheckdefaults)
    class UInputTrigger : public UObject
    {
        GENERATED_BODY()


    protected:

        // Default implementations of overridable functionality.
        // C++ trigger implementations should override these directly.
        virtual ETriggerType GetTriggerType_Implementation() const { return ETriggerType::Explicit; }

        // Triggers on actuation.
        UE_API virtual ETriggerState UpdateState_Implementation(const UEnhancedPlayerInput* PlayerInput, FInputActionValue ModifiedValue, float DeltaTime);

    public:
        // Point at which this trigger fires
        UPROPERTY(EditAnywhere, Config, BlueprintReadWrite, Category = "Trigger Settings")
        float ActuationThreshold = 0.5f;

        /* Decides whether this trigger ticks every frame or not.
        * This WILL affect performance and should only be used in specific custom triggers.
        */
        UPROPERTY(Config, BlueprintReadOnly, Category = "Trigger Settings")
        bool bShouldAlwaysTick = false;

        /*
        * Is the value passed in sufficiently large to be of interest to the trigger.
        * This is a helper function that implements the most obvious (>=) interpretation of the actuation threshold.
        */
        UFUNCTION(BlueprintCallable, Category="Trigger")
        bool IsActuated(const FInputActionValue& ForValue) const { return ForValue.GetMagnitudeSq() >= ActuationThreshold * ActuationThreshold; }

        // Value passed to UpdateState on the previous tick. This will be updated automatically after the trigger is updated.
        UPROPERTY(BlueprintReadOnly, Category = "Trigger Settings")
        FInputActionValue LastValue;	// TODO: Potential issues with this being of bool type on first tick.

        /*
        Changes the way this trigger affects an action with multiple triggers:
            All implicit triggers must be triggering to trigger the action.
            If there are any explicit triggers at least one must be triggering to trigger the action.
        */
        UFUNCTION(BlueprintCallable, BlueprintNativeEvent, Category = "Trigger")
        UE_API ETriggerType GetTriggerType() const;

        /*
        This function checks if the requisite conditions have been met for the trigger to fire.
        Returns Trigger State None		 - No trigger conditions have been met. Trigger is inactive.
                Trigger State Ongoing	 - Some trigger conditions have been met. Trigger is processing but not yet active.
                Trigger State Triggered - All trigger conditions have been met to fire. Trigger is active.
        */
        UFUNCTION(BlueprintCallable, BlueprintNativeEvent, Category = "Trigger")
        UE_API ETriggerState UpdateState(const UEnhancedPlayerInput* PlayerInput, FInputActionValue ModifiedValue, float DeltaTime);

        /** Determines what kind of trigger events can happen from the behavior of this trigger. */
        virtual ETriggerEventsSupported GetSupportedTriggerEvents() const { return ETriggerEventsSupported::Instant; }

        /**
        * Returns true if the the ETriggerEvent is can be triggered based off of the ETriggerEventsSupported.
        */
        static UE_API bool IsSupportedTriggerEvent(const ETriggerEventsSupported SupportedEvents, const ETriggerEvent Event);

        /** Returns true when all other triggers should be blocked, i.e. chords block when not triggered. */
        virtual bool IsBlocking(const ETriggerState State) const { return false; }
            
        // Provide debug output for use with ShowDebug EnhancedInput. Return an empty string to disable display.
        virtual FString GetDebugState() const { return FString(); }
    };
```

```c++
void SMySlate::ChatCommitted(const FText& Text, ETextCommit::Type CommitType)
{
	if (CommitType == ETextCommit::OnEnter)
	{
		if (OwnerController.IsValid())

		}

		ChatInput->SetText(FText::GetEmpty());
```
