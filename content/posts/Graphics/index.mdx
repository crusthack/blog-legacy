# 개요
- 그래픽스란? 컴퓨터 모니터에 그림그리는 기술
- 거의 대부분 애플리케이션들이 그래픽 API를 호출해 시각적 표현을 한다고 볼 수 있음.  
(더 저수준으로 내려간다면 직접적인 드라이버 호출, 임베디드 시스템)
- 애플리케이션에서 그래픽 API를 호출하면, 그래픽 드라이버(Nvidia, AMD...)가 gpu에게 명령을 내림.
- 그래픽 카드는 또 하나의 산술 장치로, 그래픽 연산 같은 저비용 다량 발생 작업을 하기에 적합함.  
gpu를 통해 작업을 최적화하는걸 하드웨어 가속이라고 함. 

## 학습 목적
- Unity나 Unreal Engine같은 게임 엔진의 내부 파이프라인을 이해하고 최적화할 수 있는 기반 지식을 쌓기 위해
- 콘솔 출력을 넘어서 모니터에 그림을 그려 시각적 표현을 하는 법을 배우기 위해

# 그래픽 API
## DirectX(Windows)
- Microsoft에서 관리하는 윈도우 전용 그래픽 라이브러리
- 데스크탑 게임은 대부분 윈도우 기반으로 나오기 때문에 대중적인 그래픽 라이브러리
- 현재 12버전까지 나와있으며, 학습을 위해서는 11버전을 배운 뒤 12를 학습하는게 보통
- [MSDN](https://learn.microsoft.com/en-us/windows/win32/directx)

## OpenGL, Vulkan(Cross Platform)
- 크로노스 그룹에서 관리하는 크로스 플랫폼 그래픽 라이브러리
- OpenGL 학습 이후 Vulkan을 학습하는게 보통
- [openGL](https://www.opengl.org/Documentation/Documentation.html)
- [Vulkan](https://docs.vulkan.org/spec/latest/index.html)
