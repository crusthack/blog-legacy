# 소개
- 네트워크 프로그래밍에 주로 관심을 두고, 소켓프로그래밍(Winsock, C# Socket)을 주로 학습하였습니다.  
현재는 Unity 엔진을 통해 게임 만드는 법을 학습하고 있으며, 멀티 플레이 가능한 게임을 제작해 각종 게임 시스템과 동기화 기술을 공부하려고 하고 있습니다.  

# 관심 분야
- 컴퓨터 네트워크 및 네트워크 보안
- 그래픽스(DirectX), 오디오(WASAPI)
- Windows

# 선호 언어
- C#  
(Unity, ASP.Net Core, 기타 고수준 애플리케이션)
- C++  
(코딩 테스트, Winsock, Unreal Engine, DirectX)
- TypeScript  
(Next.js)

# 주요 프로젝트 
### 네트워크 라이브러리 제작 및 유니티에 적용 
    - [Unity 2D Multi - 블로그 설명](https://crusthack.github.io/blog/Project/Unity2DMulti)
    - 기술 스택: `c#`, `socketProgramming`, `protobuf`, `unity`
    - c#을 활용하여 소켓통신 네트워크 라이브러리를 제작한 후 간단한 채팅 서버, 게임 서버 제작한 후 유니티에 적용해 멀티플레이 게임을 제작하였습니다. 
    - 릴레이 서버를 통한 멀티플레이 방식을 사용했고, 채팅, 게임 룸 생성 및 참가, rpc, 게임 동기화를 구현해보았습니다.

# 개발 공부 이력
### 2024년
- 컴퓨터공학과 입학
- Python을 시작으로 C, C++, C#, Java, JavasScript등 각종 언어들을 잡다하게 학습하였음. 
- 각종 책을 잡다하게 보면서 여러 컴공 과목들에 대한 지식을 얕게 습득하였음. 이후 공부에 많은 도움이 되었다고 생각 

### 2025년
- Winsock과 C#을 통해 소켓프로그래밍을 학습하였음. 네트워크 라이브러리를 제작한 뒤 가벼운 Unity 게임에 적용해봄. 
- Unreal을 학습하려고 하였으나, 세부적인 코드 하나하나 들여다보며  
내부적인 동작까지 학습하고자하는 시도를 하여 가성비가 안 나왔으며 결과적으로 실패하였음.  
프레임워크나 새로운 기술을 어떻게 학습해야 하는지에 대한 고찰을 하게 됨. 
- 웹 수업을 통해 Next.js를 배우고서 깃허브 페이지 배포를 통해 블로그 개발을 시작함. 

### 2026년(계획)
- Unity와 ASP.Net Core를 사용해 웹 통신 기반 멀티 플레이 게임을 제작해보는 프로젝트를 수행중
- DirectX를 공부해보고자 함. 오디오 라이브러리 WASAPI 또한 관심이 있음. 
- Rust를 통한 gui(iced)프로그래밍과 LSP(tower-lsp) 구현에 관심이 있음.
