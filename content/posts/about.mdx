# 소개
- 네트워크 프로그래밍에 주로 관심을 두고, 소켓프로그래밍(Winsock, C# Socket)을 주로 학습하였습니다.  
현재는 Unity 엔진을 통해 게임 만드는 법을 학습하고 있으며, 멀티 플레이 가능한 게임을 제작해 각종 게임 시스템과 동기화 기술을 공부하려고 하고 있습니다.  
[링크](https://crusthack.github.io/blog/Project/Unity)

# 관심 분야
- 컴퓨터 네트워크 및 네트워크 보안
- 게임 개발 및 엔진 공부 
- 그래픽스(DirectX), WinAPI

# 선호 언어
- C#  
(Unity, ASP.Net Core, 기타 고수준 애플리케이션)
- C++  
(코딩 테스트, Winsock, Unreal Engine, DirectX)
- TypeScript  
(Next.js)

# 주요 프로젝트 
### 네트워크 라이브러리 제작 및 유니티에 적용 
    - [Unity 2D Multi - 블로그 설명](https://crusthack.github.io/blog/Project/Unity2DMulti)
    - 기술 스택: `c#`, `socketProgramming`, `protobuf`, `unity`
    - c#을 활용하여 소켓통신 네트워크 라이브러리를 제작한 후 간단한 채팅 서버, 게임 서버 제작한 후 유니티에 적용해 멀티플레이 게임을 제작하였습니다. 
    - 릴레이 서버를 통한 멀티플레이 방식을 사용했고, 채팅, 게임 룸 생성 및 참가, rpc, 게임 동기화를 구현해보았습니다.
