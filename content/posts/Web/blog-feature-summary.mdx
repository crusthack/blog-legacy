# 개요
- 이 문서는 블로그에 추가한 기능들을 한 번에 확인하기 위한 정리 문서다.
- 일반 포스트와 슬라이드 뷰에서 모두 확인할 수 있는 예시를 포함한다.
- 슬라이드 테스트는 `/Web/blog-feature-summary/slide` 경로에서 확인한다.

```txt title="테스트 경로"
/Web/blog-feature-summary
/Web/blog-feature-summary/slide
```

# 1. MDX / MD 포스트 로딩
- 포스트 로더는 `.mdx`뿐 아니라 `.md` 파일도 읽는다.
- `content/posts` 아래에 있는 `.mdx`, `.md` 파일이 포스트 후보가 된다.
- 파일명에서 확장자를 제거한 값이 slug가 된다.

```txt title="지원 파일 예시"
content/posts/Web/example.mdx
content/posts/Web/example.md
```

## 빈 파일 생략
- 파일 내용이 완전히 비어 있으면 포스트로 등록하지 않는다.
- frontmatter만 있고 본문이 비어 있는 파일도 생략한다.
- 빈 파일 때문에 포스트 페이지나 슬라이드 생성 중 오류가 나는 상황을 줄이기 위한 처리다.

# 2. Gray Matter 필드
- 기본적으로 아래 필드를 사용한다.

```md title="frontmatter"
---
title: '글 제목'
date: '2026-05-28'
description: '글 설명'
titleSlide: false
---
```

## title
- 글 제목이다.
- 없으면 slug를 제목으로 사용한다.

## date
- 글 날짜다.
- 없으면 빈 문자열로 처리한다.

## description
- 글 설명이다.
- 없으면 빈 문자열로 처리한다.

## titleSlide
- 슬라이드 뷰에서 첫 제목 슬라이드를 만들지 여부를 정한다.
- 기본값은 `true`다.
- `false`로 지정하면 본문 슬라이드부터 시작한다.

```md title="제목 슬라이드 생략"
---
title: '발표 자료'
date: '2026-05-28'
titleSlide: false
---
```

# 3. VS Code Frontmatter 스니펫
- `.vscode/markdown.code-snippets`에 Markdown/MDX용 스니펫을 추가했다.
- 새 `.md` 또는 `.mdx` 파일에서 `post`를 입력하고 `Ctrl + Space`를 누르면 frontmatter 템플릿을 삽입할 수 있다.

````json title=".vscode/markdown.code-snippets"
{
  "Blog Post Frontmatter": {
    "scope": "markdown,mdx",
    "prefix": ["post", "frontmatter", "graymatter"],
    "body": [
      "---",
      "title: '${1:${TM_FILENAME_BASE}}'",
      "date: '${CURRENT_YEAR}-${CURRENT_MONTH}-${CURRENT_DATE}'",
      "description: '${2}'",
      "titleSlide: ${3|true,false|}",
      "---",
      "",
      "# ${1:${TM_FILENAME_BASE}}",
      "",
      "$0"
    ]
  }
}
````

## 사용 순서
1. `content/posts/Web/new-post.mdx`를 만든다.
2. 파일 맨 위에서 `post`를 입력한다.
3. `Ctrl + Space`를 누른다.
4. `Blog Post Frontmatter`를 선택한다.
5. `Tab`으로 필드를 채운다.

# 4. MDX 컴포넌트 등록 구조
- MDX에서 사용할 React 컴포넌트와 MDX 플러그인 설정을 `lib/mdx.tsx`로 모았다.
- 일반 포스트와 슬라이드 페이지가 같은 레지스트리를 사용한다.
- 새 컴포넌트를 추가할 때 여러 파일에 반복해서 등록하지 않아도 된다.

```tsx title="lib/mdx.tsx"
const interactiveMdxComponents = {
  CipherPlayground,
  FancyShowcase,
};
```

## 새 컴포넌트 추가 흐름
1. `components/NewComponent.tsx`를 만든다.
2. `lib/mdx.tsx`에서 import한다.
3. `interactiveMdxComponents` 또는 `createPostMdxComponents`, `createSlideMdxComponents`에 등록한다.
4. MDX에서 `<NewComponent />`로 사용한다.

# 5. 카테고리 포스트 링크

- 현재 글과 `index` 글은 기본적으로 제외한다.


# 9. 슬라이드 배경 지정
- gray-matter의 `background` 필드로 슬라이드 뷰의 배경을 지정할 수 있다.
- 일반 포스트 화면에는 적용하지 않고, `/slide` 경로에서만 적용된다.
- 이 문서는 `rgb(236, 253, 245)` 색상을 지정했으므로 슬라이드 뷰에서 옅은 민트색 배경이 보여야 한다.

```md title="색상 배경"
---
background:
  color: 'rgb(236, 253, 245)'
---
```

## 축약 문법

# 10. 슬라이드 뷰 기능
## 현재 슬라이드 유지
- 슬라이드 이동 시 URL hash가 `#slide-3`처럼 갱신된다.
- 새로고침해도 마지막 슬라이드를 유지한다.
- 직접 특정 슬라이드로 접근할 수도 있다.

```txt title="직접 접근"
/Web/blog-feature-summary/slide#slide-3
```

## 전체화면 UI 자동 숨김
- 전체화면에서는 상단바와 하단바가 기본적으로 숨겨진다.
- 마우스를 움직이면 잠시 나타난다.
- 목차 또는 그리기 모드가 켜져 있으면 UI가 유지된다.

## 슬라이드 그리기
- 펜 버튼을 누르면 슬라이드 위에 직접 그릴 수 있다.
- 색상과 굵기를 조절할 수 있다.
- `Clear` 버튼으로 현재 슬라이드의 그림을 지운다.
- 슬라이드를 넘기면 그린 내용은 초기화된다.

### 단축키
- `d`: 그리기 모드 켜기/끄기
- `c`: 그리기 내용 지우기
- `f`: 전체화면 전환
- `t`: 목차 열기/닫기
- `p`: 프린트

## 코드블럭 내부 스크롤
- 슬라이드 뷰의 코드블럭은 내부 스크롤을 가진다.
- 긴 코드가 있어도 슬라이드 전체를 강제로 늘리지 않는다.
- 슬라이드에서는 코드 폰트를 일반 포스트보다 살짝 크게 표시한다.

# 체크리스트
- 이 문서가 일반 포스트에서 정상 렌더링된다.
- `/Web/blog-feature-summary/slide`에서 제목 슬라이드 없이 본문부터 시작한다.
- `CategoryPostLinks`가 현재 Web 카테고리 글 목록을 보여준다.
- `FancyShowcase` 탭과 슬라이더가 동작한다.
- `CipherPlayground`에서 카이사르/비즈네르 결과가 바뀐다.
- 코드블럭 파일명이 표시된다.
- 슬라이드 뷰에서 새로고침 후 현재 슬라이드가 유지된다.
- 슬라이드 뷰에서 펜 버튼, 색상, Clear 버튼이 동작한다.
