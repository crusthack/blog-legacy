# MDX 문법 및 사용 가이드

MDX는 **Markdown for the component era**라는 슬로건처럼, 마크다운의 간결함과 React 컴포넌트의 강력한 기능을 결합한 문서 형식입니다. 이 가이드는 기본적인 마크다운 문법부터 MDX만의 고유한 기능까지 상세히 다룹니다.

---

## 1. 기본 마크다운 문법 (Standard Markdown)

### 1.1 제목 (Headings)
`#`의 개수로 제목의 수준을 결정합니다.

### 1.2 텍스트 강조 (Emphasis)
- *기울임꼴*: `*text*` 또는 `_text_`
- **굵게**: `**text**` 또는 `__text__`
- ***굵은 기울임꼴***: `***text***`
- ~~취소선~~: `~~text~~`

### 1.3 인용구 (Blockquotes)
`>` 기호를 사용하며, 중첩해서 사용할 수도 있습니다.

> MDX는 마크다운 안에서 컴포넌트를 쓸 수 있게 해줍니다.
>> 정말 편리하죠?

## 2. GFM (GitHub Flavored Markdown)

우리 블로그는 `remark-gfm` 플러그인을 지원하여 다음 기능을 사용할 수 있습니다.

### 2.1 작업 목록 (Task Lists)
- [x] MDX 이해하기
- [ ] 멋진 포스트 작성하기
- [ ] 블로그 꾸미기

### 2.2 표 (Tables)
파이프(`|`)와 하이픈(`-`)을 사용하여 깔끔한 표를 만들 수 있습니다.

| 기능 | 지원 | 설명 |
| :--- | :---: | :--- |
| **JSX** | ✅ | 컴포넌트 직접 사용 가능 |
| **Expressions** | ✅ | `{1 + 1}` 같은 JS 표현식 |
| **GFM** | ✅ | GitHub 스타일 문법 지원 |

### 2.3 각주 (Footnotes)
문장 뒤에 각주를 달 수 있습니다.[^1]

[^1]: 각주는 페이지 하단에 자동으로 모여서 표시됩니다.

## 3. 코드 블록과 하이라이팅

`rehype-pretty-code`와 `shiki`를 사용하여 아름다운 코드 하이라이팅을 제공합니다.

### 3.1 인라인 코드
문장 중간에 `const x = 10`처럼 짧은 코드를 넣을 수 있습니다.

### 3.2 다중 라인 코드 블록
언어를 명시하여 구문 강조를 적용합니다.

```typescript:lib/posts.ts
interface Post {
  title: string;
  date: string;
  content: string;
}

function getPost(id: string): Post {
  // logic here
}
```

## 4. 수학 수식 (Math & LaTeX)

`remark-math`와 `rehype-katex`를 통해 복잡한 수식을 렌더링할 수 있습니다.

- **인라인 수식**: $E = mc^2$
- **블록 수식**:

$$
I = \int_{a}^{b} f(x) dx
$$

## 5. MDX 고유 기능 (The Power of MDX)

MDX의 진정한 가치는 마크다운 문서 안에서 JavaScript와 React를 사용할 수 있다는 점에 있습니다.

### 5.1 JSX 컴포넌트 사용
HTML 태그나 사용자 정의 React 컴포넌트를 마크다운에 직접 삽입할 수 있습니다.

<div style={{ padding: '20px', backgroundColor: '#f0f0f0', borderRadius: '8px', border: '1px solid #ccc' }}>
  ### 💡 알림
  이 박스는 MDX 내부에서 **직접 작성된 HTML/JSX**입니다. 마크다운 문법도 내부에서 동작합니다!
</div>

### 5.2 자바스크립트 표현식 (Expressions)
중괄호`{}`를 사용하여 JS 코드를 실행한 결과를 출력할 수 있습니다.

- **산술 연산**: 10 + 20 = {10 + 20}
- **현재 시간**: {new Date().toLocaleDateString()}
- **조건부 렌더링**: {true ? "✅ 성공" : "❌ 실패"}

### 5.3 이미지 처리 (MdxImage)
우리 블로그는 커스텀 `MdxImage` 컴포넌트를 사용하여 이미지를 최적화합니다.
