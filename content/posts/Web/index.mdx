# 웹 기초
- HTML(Hyper Text Markup Language): 웹 페이지 내의 요소들을 선언할 수 있는 텍스트 파일. 
- CSS(Cascading Style Sheets): html 원소들의 스타일을 지정하게 해주는 서식 파일. 
- Java Script: 웹 페이지에서 동적인 상호작용을 할 수 있도록 브라우저 환경에서 돌아가는 프로그래밍 언어.
- Web Browser: 위의 3개 요소를 기반으로 사용자에게 웹서비스를 쉽게 사용할 수 있도록 도와주는 프로그램.  
    단순 웹 서비스 말고도 로컬 파일 열람과 같은 여러 유틸리티를 제공.

# Node.js
- JS의 런타임 실행환경. 웹 브라우저 없이 js 코드를 실행하게 해줌.
- NPM(Node Package Manager)을 통해 여러 개발 도구를 쉽게 관리할 수 있게 해줌
- TypeScript, React, Express.js, Vue.js, Next.js, 등... 과 같은 여러 기술들을 사용할 수 있는 플랫폼(구글 gemini도 npm을 통해 설치)
