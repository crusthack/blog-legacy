# MDX 슬라이드 시스템 개요
본 블로그는 작성된 MDX 포스트를 기반으로 발표용 슬라이드를 자동 생성하고, 이를 PDF로 저장하거나 인쇄할 수 있는 시스템을 갖추고 있습니다. 이 시스템은 크게 **콘텐츠 분할 엔진**, **동적 UI 렌더러**, **프린트 최적화 뷰**의 세 부분으로 구성됩니다.

## 1. 콘텐츠 분할 엔진 (`lib/slides.ts`)
MDX 본문을 분석하여 여러 개의 슬라이드 단위로 쪼개는 핵심 로직입니다.

### 가중치 기반 패킹 (Weight-based Packing)
단순히 개수 단위로 자르는 대신, 각 요소(아톰)에 가중치를 부여하여 한 슬라이드에 적절한 양의 내용이 들어가도록 합니다.
- **최대 가중치 (`MAX_LINES_PER_SLIDE`)**: 16 (현재 기준)
- **일반 텍스트/리스트**: 가중치 1.0
- **이미지/테이블**: 가중치 8.0
- **코드 블록**: 가중치 **0** (슬라이드 분할에 영향을 주지 않고 텍스트와 함께 묶임)

### 헤더 기반 구획 분할
- 모든 헤더(`#` ~ `#######`)는 새로운 섹션의 시작점으로 간주되어, 가급적 헤더 직전에서 슬라이드가 넘어가도록 설계되었습니다.
- 레벨 3 헤더(`###`) 이하부터는 `isForce` 플래그를 통해 내용량과 상관없이 무조건 새로운 슬라이드를 시작하게 할 수도 있습니다.

## 2. 동적 UI 및 코드 블록 (`components/CodeBlock.tsx`)
슬라이드 뷰에서는 일반 포스트와 다른 사용자 경험을 제공합니다.

### 유동적 코드 블록 높이
코드 블록은 슬라이드 내의 **다른 내용물의 가중치**에 따라 높이가 실시간으로 결정됩니다.
- **내용이 적을 때**: 최대 **82vh**까지 확장되어 코드를 시원하게 보여줍니다.
- **내용이 많을 때**: 제목이나 설명문을 가리지 않도록 최소 **30vh**까지 축소되며 내부에 스크롤바가 생깁니다.
- 계산식: `max(30, 82 - (기타내용가중치 * 3.25))vh`

### 네비게이션 및 단축키
- **방향키/Space**: 이전/다음 슬라이드 이동
- **J / K**: 섹션(주요 헤더) 단위로 빠르게 건너뛰기
- **F**: 전체 화면 모드 토글
- **T**: 계층형 목차(TOC) 사이드바 열기
- **P**: 인쇄/PDF 저장 창 열기

## 3. 프린트 및 PDF 저장 시스템
브라우저의 인쇄 기능을 활용하여 슬라이드를 깔끔한 PDF 문서로 변환합니다.

### 이중 뷰 구조 (`SlideContent.tsx`)
화면에는 현재 슬라이드만 보여주는 **Interactive View**와, 인쇄 시에만 나타나는 **Print View**가 공존합니다.
- **Interactive View**: `fixed inset-0`으로 고정되어 있으며 `print:hidden`으로 인쇄 시 제외됩니다.
- **Print View**: 평소에는 `opacity-0`, `h-0`으로 숨겨져 있으나, 인쇄 시(`@media print`) 모든 슬라이드가 수직으로 나열되며 나타납니다.

### CSS 인쇄 최적화 (`globals.css`)
- `page-break-after: always`: 각 슬라이드 끝에서 강제로 페이지를 넘깁니다.
- `-webkit-print-color-adjust: exact`: 코드 블록의 배경색과 테마를 인쇄물에서도 그대로 유지합니다.
- 가로 모드(`landscape`) 최적화 레이아웃을 제공합니다.

# 기술 스택
- **Next.js 15 (App Router)**
- **next-mdx-remote**: 마크다운 렌더링
- **Tailwind CSS**: 유동적 레이아웃 및 애니메이션
- **Shiki / rehype-pretty-code**: 코드 하이라이팅
