## 잘못된 쌍 개수 세기
- 문제로 제시된 pair로 구성된 일반화 리스트가 바로 이해가 안 됐어서 제 식대로 이해하기로 함.

### 데이터 구조(C언어)
```c
typedef struct _Data* (*Bop)(struct _Data* as);

    struct _Data* d[2];
} Pair;
```

### F# 재구성
```f#
type Data(value: Value) = 
    let _value = value

    member _.value
        with get() = _value

and Value =
    | Nil
    | CV of char
    | PV of Pair

and Pair(car: Data, cdr: Data) =
    let mutable _car = car
    let mutable _cdr = cdr

    member this.car 
        with get() = _car
        and set(data: Data) = _car <- data
    
    member this.cdr
        with get() = _cdr
        and set(data: Data) = _cdr <- data

// tag는 f#에선 union구조체에 대해 알아서 패턴 매칭 되므로 생략됨
```

### 문제 풀이 사고 과정
- 각 노드는 Data 노드, Data는 pair가 될 수도 있고 단순 자료(char형 자료 'a', 'b', 'c')를 저장하는 데이터 노드일 수 있음.
- 3개의 pair로만 이루어진 리스트 구조 -> Pair인 Data노드는 3개 고정
- 문제 예시대로 ('a' . ('b' . ('c' . nil)))인 구조면,  
count_pair(p3) => (0) + 1 = 1, (이하 count_pair은 fn)  
fn(p2) => (0 + 1) + 1 = 2, fn(p1) => (0 + 2) + 1 = 3이므로 제대로 연산이 됨.
- 여기에서 pair가 3개인 채로 fn(p1)의 값이 3을 넘길려면, 내부적으로 하나의 pair를 중복해서 가르키는 포인터들이 있어야 됨. 즉, car이 다른 pair 참조.
- pn이 pm을 가르킬 경우(n > m) 함수는 무한 재귀에 빠지게 됨

## 고유한 쌍 개수 세기
- 함수가 이미 탐색한 노드를 해쉬값으로 저장해두고서 이미 저장된 노드(해쉬)면 0을 반환하도록 수정
- 처음 작성한 count 함수는 7을 반환하지만, 새로 작성한 count_pairs_v2는 3을 반환함
### 코드
```f#
let rec count_pairs(data: Data) = 
    // printfn "counting..."
    match data.value with
    | PV pair -> (count_pairs pair.car + count_pairs pair.cdr) + 1
    | _ -> 0

let count_pairs_v2 (data: Data) : int =
    let visited = ResizeArray<int>()
 
    let rec loop (data: Data): int =
        if visited.Contains(data.GetHashCode()) then 0
        else
            visited.Add(data.GetHashCode())
            match data.value with 
            | PV pair->
                loop(pair.car) + loop(pair.cdr) + 1
            | _ -> 0
 
    loop data

let p3 = Data(PV (Pair(Data(CV 'c'), Data Nil)))
let p2 = Data(PV (Pair(p3, p3)))
let p1 = Data(PV (Pair(p2, p2)))

// p3의 cdr p1으로 교체
// match p3.value with

//     pairInstance.cdr <- p1
// | _ -> 
//     ()


printfn "v1: %d" (count_pairs p1)
printfn "v2: %d" (count_pairs_v2 p1)

// 출력
// v1: 7
// v2: 3
```

## 순환 탐지

```f#
let check_cycle (data: Data) : bool =
```

## 상수 공간 순환 탐지
- 방문한 모든 노드를 저장하는 기존 방식대로라면 노드 n개를 모두 저장해야 하기에 공간 복잡도가 O(n)이 됨. 이를 O(1) 상수로 푸는게 문제
- 포인터 한 개 짜리, cdr로만 이루어진 단방향 리스트로 가정. 

### 풀이 1. 첫번째 노드에 대해서만 순환 검사
- 끝과 시작이 연결된 환형 리스트를 간주하여 첫번째 노드의 해시값을 가지고만 뒤의 노드들 해쉬 비교해서 순환 탐지

#### 문제점
- 순환 지점이 첫 노드로 이어지는게 아닌 중간노드로 이어지는 경우, 즉 p3가 p2를 가리키는 경우에 대해서는 순환 탐지 불가

### 풀이 2. 모든 노드의 해시값에 대해서 검사
- 1의 방식을 모든 노드들에 대해 검사함, 검사 순서는 꼬리 노드부터 머리 노드까지...
#### 문제점
- 순환 여부도 모르고 꼬리 노드도 모르는데 검사를 시작할 수도 없음 
- 하게 되면 시간 복잡도가 O(N^2)임

### 풀이 3. 자료구조 비틀기
- pair에 변수 추가해서, 순환 검사하는 동안 false -> true 하고서 true인 pair 만나면 순환 구조 감지

#### 문제점
- 결국에 노드마다 상태 하나 더 저장하게 하면 공간 비용 O(N) 아님?

### 풀이 4. 포인터 바꾸기
- 1번 풀이 사용, 다만 탐색하는 노드들을 2번째 노드부터는 그 이전 노드로 cdr을 교체
- 즉, 순환구조가 생기면 무조건 첫 번째 헤드 노드로 돌아오게 돼 있음. -> 순환 탐지 완료
- 순환 없이 nil 생기면, 다시 돌아가면서 cdr 원상복구 
- 메모리 추가 사용 X, 시간 복잡도 O(n) (최대 2n)

#### F# 코드    
```f#
type Data(value: Value) = 
    let _value = value

    member _.value
        with get() = _value

and Value =
    | Nil
    | CV of char
    | PV of Pair

and Pair(car: Data, cdr: Data) =
    let mutable _car = car
    let mutable _cdr = cdr

    member this.car 
        with get() = _car
        and set(data: Data) = _car <- data
    
    member this.cdr
        with get() = _cdr
        and set(data: Data) = _cdr <- data

let rec count_pairs(data: Data) = 
    // printfn "counting..."
    match data.value with
    | PV pair -> (count_pairs pair.car + count_pairs pair.cdr) + 1
    | _ -> 0

let count_pairs_v2 (data: Data) : int =
    let visited = ResizeArray<int>()
 
    let rec loop (data: Data): int =
        if visited.Contains(data.GetHashCode()) then 0
        else
            visited.Add(data.GetHashCode())
            match data.value with 
            | PV pair->
                loop(pair.car) + loop(pair.cdr) + 1
            | _ -> 0
 
    loop data

let check_cycle (data: Data) : bool =
    let visited = ResizeArray<int>()

    let rec loop (data: Data): bool =
        if visited.Contains(data.GetHashCode()) then true
        else
            visited.Add(data.GetHashCode())
            match data.value with 
            | PV pair -> loop(pair.cdr)
            | _ -> false

    loop data

let change_next (data: Data) (nextD: Data) = 
    match data.value with
    | PV pairInstance -> 
        pairInstance.cdr <- nextD
    | _ -> 
        ()

let check_cycle_v2(data: Data) : bool =
    match data.value with
    | PV pair ->
        let mutable current = pair.cdr
        let mutable previous = data
        let first = data
        let mutable foundCycle = false
        let mutable isFinished = false

        while not isFinished do
            if current.GetHashCode() = first.GetHashCode() then
                foundCycle <- true
                isFinished <- true
            else
                match current.value with
                | PV p ->
                    let next = p.cdr
                    change_next data previous 
                    
                    previous <- current
                    current <- next
                | _ -> 
                    isFinished <- true

        foundCycle
    | _ -> false

let p3 = Data(PV (Pair(Data(CV 'c'), Data Nil)))
let p2 = Data(PV (Pair(p3, p3)))
let p1 = Data(PV (Pair(p2, p2)))

printfn "v1: %d" (count_pairs p1)
printfn "v2: %d" (count_pairs_v2 p1)

printfn "before cycle"

printfn "%b" (check_cycle p1)
printfn "%b" (check_cycle_v2 p1)


// p3의 cdr p1으로 교체
change_next p3 p1

printfn "after cycle"


printfn "%b" (check_cycle p1)
printfn "%b" (check_cycle_v2 p1)

// 출력
// v1: 7
// v2: 3
// before cycle
// false
// false
// after cycle
// true
// true
```
