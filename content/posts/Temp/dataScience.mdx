# 데이터 과학

## 개요
- 탐색, 추론, 예측
- **탐색**을 통해 데이터 수집 및 시각화 및 통계화 -> **추론**을 통해 신뢰성 있는 결론 도출 -> 머신러닝을 활용하여 새로 생성된 데이터를 **예측**을 통해 추정
- 비판적 사고, 귀납적 추론
- 데이터 마이닝, 빅데이터, 머신러닝, 예측분석, 실시간 데이터 분석, 

## 데이터

### 변수간 관계
- 상관관계
- 인과관계

- 허위 상관
- 무작위 대조 실험

### DIKW(Data, Info, Knowledge, wisdom)
- Data: 단위 기호
- Information: 해석이 담긴 데이터
- knowledge: 추상적인 정보
- wisdom: 사람의 판단, 부가 정보 예측

### 데이터 속성
1. 명목(Nominal): =, /= 둘로 갈림. 이퀄 낫이퀄밖에 없음. 그룹단위로 묶을 수 있음
2. 순서(Ordinal): >, \<. 순서(우열)은 존재하지만 간격에 의미는 없음. 
3. 구간(Interval): +, -. 우열이 존재하며 간격에 수적 의미가 담김. None이라는 값은 존재하지 않음. 
4. 비율(Ratio): *, /. 우열과 간격이 존재하며 0이라는 부존재(null)가 존재. 
- 이산 속성: 셀 수 있는 값. 
- 이진 속성: 이산 속성에 속함
- 연속 속성: 실수값

### 데이터 분석을 위한 구분
- 차원: 속성의 개수. 많아질수록 복잡해짐
- 희소성: 대부분의 값이 0, null인 데이터
- 해상도: 데이터 측정의 세밀함 정도
- 크기: 데이터의 규모

### 정형데이터 비정형데이터
- 정형 데이터 - table 구조
- 비정형 데이터 - 분석을 위한 전처리 필요함. 
- 반정형 데이터 - 대부분 key-value 구조를 가지는 데이터 구조. 정형보다 유연하고 비정형보다 분석이 쉬움

### 관계형 데이터와 비관계형 데이터
- 관계형 데이터 -> 테이블, RDBMS
- 비관계형 데이터 -> 키밸류, 문서형(참조형), 그래프, 부분 테이블

### 데이터 셋 종류
- Record(Table)
- Ordered
- Graph
- Transaction

## 시각화
### EDA(Exploratory Data Analysis)
- 요약 통계량과 시각화를 통해 데이터가 스스로의 정보를 말하게 하는 분석 접근법. 
- 요약 통계량: 평균, 중앙값, 표준편차, 사분위수, 상관계수... 데이터를 수치로 압축
- 시각화: 히스토그램, 박스플롯, 산점화, 히트맵 등 패턴이나 구조를 드러냄

### 시각화 원칙
- 데이터만 강조
- 왜곡 배제
- 장식 배제
- 축과 단위 명징
- 목적에 맞는 그래프

### 시각화 법칙
- 시각적 표현은 최대한 자제
- 2차원 3차원 표현 방식 자제, 길이 면 부피
- 막대그래프의 값은 0에서부터 시작, 축의 라벨과 단위, 스케일은 선형적으로
- 종횡비 조절, 그래프 기울기가 45도 정도가 되도록

### 테이블 표현
- 행 정렬: 비교 용이
- 열 정렬: 값 타입 관계 강조
- 정밀도(실수)표현은 우측 정렬
- 특정 항목 **강조**하기 위한 글꼴, 색상 사용
- 긴 설명 지양

### 선 그래프
- 추세선만 보여주는게 아니라 데이터 점으로 표시
- 범주형 데이터에는 사용 지양
- 적합선과 점 같이 사용

### 산점도
- 2차원 데이터를 표현하기 위한 차트

### 막대그래프, 원그래프
- 막대그래프: 비율 및 빈도 표시
- 원 그래프: 전체 비율을 보여주기 용이

### 히스토그램
- 연속형 변수의 분포 시각화
- 최빈값 표시 용이

### 시각화 원리
- 음영 처리된 영역의 크기는 데이터 값에 비례
- 선형 척도를 나타내는 막대는 항상 0에서 시작
- 값간에 어떤 차이가 있는지 명시적으로 표현
- log scale 허용. 얜 1에서부터 시작
- 웬만하면 막대 그래프를 원 그래프보다 선호

### 색칠 놀이
- 색상은 msg정도로만 사용
- 범례에서 순서 맞추기
- 직접적인 라벨링 가능
- 차트, 축, 범례에 제목 사용

### 테이블 원칙
- 수직선 사용 x
- 행 사이에 가로선 x
- 텍스트는 왼쪽 정렬
- 숫자는 오른쪽 정렬
- 단일문자 포함되는 열은 가운데 정렬
- 헤더또한 같이 정렬

### 격자선
- 적절한 격자 선은 값간 비교에 도움을 줌
- 다만 시각적 노이즈가 될 수도 있음

### label
- 라벨에 주석 주의

### 시각 강조 표현
- 표현하고 싶은 주요 속성을 강조 가능
- 색상, 색조, 채도, 명도: 범주형 데이터
- 형태, 크기, 방향, 모양, 곡률: 정량적 데이터
- 공간 위치: ㅇㅅㅇ
- 움직임, 깜빡임, 방향 -> 인터렉티브 표현

### 강조 순위

- 근접성

### Anscombe’s Quartet
- 요약 통계량은 비슷하지만, 시각화 표현을 하면 완전히 달라지는 데이터셋


### EDA workflow
1. 데이터 개요 파악: 변수의 수, 데이터 타입, 결과값 확인
2. 단변량 분석: 히스토그램, 박스플롯으로 분포 형태와 이상치 탐지
3. 이변량, 단변량 분석: 산점도, 상관 행렬, 히드맵
4. 패턴과 이상치 기록: 패턴, 이상치 문서화
5. 가설 수립: 분석 결과 정리
