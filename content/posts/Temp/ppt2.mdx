# 0. 암호학 개요 
## 암호화?
- **안전한 데이터 전달과 보호**를 위해 원본 데이터를 알아보기 어려운 형태로 변환하는 과정
    - (안전하다) => 탈취, 감청, 데이터 변조 등을 방지할 수 있어야 함. 
- 암호화된 데이터는 **암호 키**를 가지고 있는 수신자가 다시 원본 데이터로 **복구**할 수 있어야 함.(**복호화**)
![암호화](enc.png)

## 디지털 세계에서의 암호화 필요성 
- 컴퓨터상에 존재하는 모든 정보는 0과 1의 비트 정보. 네트워크 상으로 전달되는 모든 디지털 신호에도 적용
- 광케이블, 와이파이(전파)로 통신되는 신호를 외부에서 쉽게 감청 가능. 특히나 전파 신호(wifi)  <br/>
    => 네트워크 통신 시에, 원본 데이터를 그대로 전송하게 되면, 그대로 정보가 탈취될 수 있음(스누핑)<br/>
- 정보 보호를 위해 암호화된 데이터로 전달함으로써 감청으로부터 안전해야함

## 암호학 
- 전송된 정보를 보호하기 위해 알고리즘을 개발하고 사용하는 학문
- 더 빠르고 간단하게 데이터 암호화-복호화를 수행하고 하고, 동시에 더 안전하게 처리할 수 있는 방법을 연구 <br/><br/><br/>

# 1. 고전 암호
## 고전 암호
주로 제1차 세계대전 이전까지 사용.
전치,대입,치환의 원리를 주로 이용하여 수계산 또는 표를 이용한 암호.

### 고전 암호의 특징
- 계산기 없어도 구현 가능한 수학적 연산 사용.
- 무차별 대입 공격에 취약.
- 반드시 복호화가 가능함. (양방향 암호화)
- 치환 암호와 전치 암호로 분류.

## 카이사르(Caesar) 암호
- 단순대치암호
- 쥴리어스 시저(Julius Caesar)가 사용한 암호 
- 역사상 가장 오래된, 단순한 치환 암호.
- 글자를 n칸 미는 형태의 단순 암호.
- 해독 방법 : 무차별 대입 공격(Bruteforce-attack), 빈도 분석법(Frequency analysis).

## 비즈네르(Vigenere) 암호
- 다중대치암호
- 프랑스 외교관인 비제네르(Blaise de Vigenere)가 고안한 암호.영어의 언어 통계적 속성을 숨기기 위함. -> 빈도 분석법과 무차별 대입 공격에 강한 내성.
- 키를 알아내어 단일문자 치환 암호로 재구성하면 빈도 분석법으로 해독 가능.
- Key 문자열을 사용하여 평문의 각 문자를 서로 다른 이동 값으로 변환.
- 오늘날 많이 사용하는 암호들의 기본형.
    Ci = (Pi+Ki) mod26

## 비즈네르 예시 
- 예) 문자열 : KEEPER, 키 : KEY K(10)+K(10)=U(20), E(4)+E(4)=I(8), E(4)+Y(24)=C(2), P(15)+K(10)=Z(25), E(4)+E(4)=I(8), R(17)+Y(24)=P(15)=>UICZIP
- 방식: 1. 키 준비.2. 원문의 한 글자 + 현재 순서의 키의 글자를 각각 행, 열에서 찾아 행/열이 교차하는 위치의 글자로 변환한다.

# 2. 현대 암호 - 비대칭 키
- 대칭키 -> 비대칭키 -> 전자서명
## 대칭키 암호
- 암호화와 복호화에 같은 키를 사용하는 방식
- 송신자와 수신자가 동일한 비밀 키를 공유해야 함
- 속도가 빠르기 때문에 실제 데이터 통신, 파일 암호화 등에 많이 사용됨

### 대칭키 암호의 문제점
- 상대방에게 키를 안전하게 전달해야 함
- 공개된 네트워크에서 키를 전달할 경우 중간에서 탈취될 위험 존재
- 공격자가 키를 획득하면 암호문 복호화 가능

=> 빠르지만, **키 공유 문제(Key Distribution Problem)** 가 존재

## 비대칭키 암호
- 서로 다른 두 개의 키를 사용하는 암호 방식. 공개키(Public Key)와 개인키(Private Key) 존재
- 공개키는 누구에게나 공개 가능
- 개인키는 소유자만 보관해야 함

### 비대칭키 동작 방식
1. 수신자는 공개키와 개인키를 생성
2. 공개키는 외부에 공개
3. 송신자는 공개키로 메시지를 암호화
4. 수신자는 자신의 개인키로만 복호화 가능

=> 공개키는 누구나 사용할 수 있지만, 실제 내용을 읽을 수 있는 사람은 개인키 소유자뿐

### 전자서명
- 전자서명을 통한 무결성, 인증, 부인방지
- 공개키로 암호화한걸 암호키로 복호화 하는 경우와 
- 암호키로 암호화한걸 공개키로 복호화 하는 경우 
- 무결성, 인증, 부인방지 자체에 대해서도 

### 비대칭키 암호의 장점
- 대칭키 암호의 키 전달 문제를 해결 가능
- 공개된 네트워크에서도 비교적 안전하게 통신 가능

##### 비대칭키 암호의 단점
- 대칭키 암호보다 연산 속도가 느림
- 많은 데이터를 직접 암호화하기에는 비효율적

=> 실제 인터넷 통신에서는  
비대칭키 암호로 대칭키를 안전하게 교환한 뒤,  
이후 실제 데이터는 대칭키 방식으로 암호화하는 경우가 많음
