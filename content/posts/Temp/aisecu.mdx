# 딥러닝 학습
- 데이터를 이용하여 파라미터(기울기, ??)를 최적화 하는 과정
1. 데이터 입력, 2. 예측 생성, 3. 오차 계산 4. 기울기 계산, 5. 파라미터 업데이트

1. 데이터 입력
- 학습데이터(x(입력), y(정답)) label -> e.g. 이미지 => 클래스, 문장 => 의미
2. 예측 생성(forward propagation)
- 입력 데이터를 신경망에 통과시켜 예측값을 계산 y = f세타(x) 예측값 = 신경망모델, 모델 파라미터(입력값)
3. 오차 계산(Loss)
- 예측값과 실제값의 차이를 계산 e.g. MSE, 크로스뭐시기 ...
4. 기울기 계산(back propagation)
- Loss가 계산되면 chain rule을 이용한 파라미터에 대한 기울기(gradiant) 계산
5. 파라미터 업데이트
- learning rate 계산?

## gradiant descent 계산 종류
1. batch gradiant descent
- 전체 Data를 사용 => 안정적인 업데이트, 계산량 많음 

2. stochostic gradiant descent(SGD)
- 하나의 Data 사용 => 빠른 업데이트, 예외상황, Noise 발생

3. Mini-Batch g.d.
- batch size(32, 64, 128)를 이용해 일부 데이터 사용 => 계산 효율, 안정적
