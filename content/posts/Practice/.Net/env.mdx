# sln, 솔루션 파일 생성하기 
- sln, 솔루션 파일은 개발자가 여러개의 프로젝트들을 쉽게 관리 하기위한 텍스트 기반의 파일입니다.  
기본적으로는 Visual Studio에서 프로젝트 관리를 하기 위한 파일이지만, Visual Studio Code에서도 활용 가능합니다.
- `dotnet sln`명령어를 사용하여 솔루션 파일을 관리합니다. 
- [dotnet sln msdn](https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-sln)

## 새 솔루션 파일 생성 
- `dotnet new sln`: 현재 디렉토리명과 일치하는 솔루션 파일을 생성합니다.
- `dotnet new sln --name MySolution`: 이름 지정 
- `dotnet new sln --output MySolution`: **MySOulution** 폴더 생성 후 해당 폴더 안에 솔루션 생성 

## 기타 솔루션 명령어 
- `dotnet sln list`: 솔루션이 참조하는 프로젝트 리스트 출력 
- `dotnet sln [<SOLUTION_FILE>] add [--in-root] [-s|--solution-folder <PATH>] <PROJECT_PATH> [<PROJECT_PATH>...]`:  
솔루션에 프로젝트 참조를 추가합니다. 
- `dotnet sln [<SOLUTION_FILE>] remove <PROJECT_PATH|PROJECT_NAME> [<PROJECT_PATH|PROJECT_NAME>...]`:  
솔루션에 프로젝트 참조를 제거합니다. 
- `dotnet sln [<SOLUTION_FILE>] migrate`: sln파일을 새로운 형식 slnx로 변경합니다. slnx는 최신 형식의 솔루션 파일입니다. 

# .Net 프로젝트 생성하기 
- [dotnet new msdn](https://learn.microsoft.com/en-us/dotnet/core/tools/dotnet-new)

## 콘솔 프로젝트 생성 
- `dotnet new console -o Console`: Console 폴더에 C# 콘솔 프로젝트 생성. 기본 언어 C# 
- `dotnet new console -n hello -lang F#`: hello 프로젝트명의 F# 콘솔 프로젝트 생성 
```cmd
dotnet new <TEMPLATE> [--dry-run] [--force] [-lang|--language {"C#"|"F#"|VB}]
    [-n|--name <OUTPUT_NAME>] [-f|--framework <FRAMEWORK>] [--no-update-check]
    [-o|--output <OUTPUT_DIRECTORY>] [--project <PROJECT_PATH>]
    [-d|--diagnostics] [--verbosity <LEVEL>] [Template options]
dotnet new -h|--help
```
## 솔루션에 프로젝트 추가하기 
- `dotnet sln add "./Console/Console.csproj"`: 현재 디렉토리의 솔루션파일에 프로젝트 파일 참조를 추가하여 관리합니다. 

# .Net 프로젝트 빌드 및 실행 
- `dotnet build`: 프로젝트/솔루션을 빌드합니다. 솔루션 디렉토리에서 입력하면 솔루션이 참조하는 모든 프로젝트를 빌드합니다. 
- `dotnet run`: 프로젝트를 빌드한 후 실행합니다. 솔루션에서 실행시 실행할 프로젝트를 지정해줘야 합니다.
- `dotnet run --project "console"`: 프로젝트 명을 지정하여 솔루션이 참조하는 프로젝트를 실행합니다.
