# .Net 개요
- .Net은 MS가 개발했으며 현재는 오픈소스로 운영되는 플랫폼으로 중간언어로 번역된 어셈블리들을 실행하기 위한 런타임 환경입니다.
- C#, F#, Visual Basic 등의 언어들은 IL(Intermediate Language)이라는 어셈블리로 컴파일됩니다.  
이후 어셈블리 실행시, IL이 JIT(Just-in-Time)컴파일러에 의해 실시간 컴파일되어, CLR(Common Language Runtime) 가상환경 위에서 실행됩니다.
- 크로스플랫폼을 지원하여 .Net 실행환경만 구성된다면 어셈블리를 곧바로 실행할 수 있습니다. 

# C#
- .Net 플랫폼에서 실행되는 Managed-Language입니다. 
- 여러가지 문법 기능하여 코드 작성이 용이한 고수준 언어입니다. 가비지컬렉터가 존재하여 메모리관리를 자동으로 해줍니다. 
- C#을 사용하는 대표적인 프레임워크로 Unity 게임 엔진과 ASP.Net 웹 서버 프레임워크가 존재합니다. 

## C#의 단점 
- C#은 언어적으로 기능이 풍부하여 개발자에게 편리한 기능들을 양껏 제공한다고 생각합니다. 
- 하지만 이에 의해 실제 언어 동작이 감춰지고 수많은 기능들 덕분에 오히려 복잡한 구조를 만들게 될 수 있다고 생각합니다.
- **Syntactic-Suger**에 빠지지 않기 위해 구문을 조심히 다룹니다.
