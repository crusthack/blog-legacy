# Next.js로 만든 MDX 블로그입니다
- 프로그래밍 학습 내용을 정리하는 데에 목적을 둔 개발자 블로그입니다.  
- 이미 일정 수준의 학습, 이해를 한 상태에서 간단하게 텍스트 기반으로 핵심만 정리하는 방식으로 포스트를 작성합니다. 
- 일반 포스트는 ~~했음으로 끝나는 비격식체로, 프로젝트 포스트는 ~~했습니다로 끝나는 격식체로 작성하는 것을 지향합니다.
