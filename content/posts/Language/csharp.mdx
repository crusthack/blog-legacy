# C# 개요
- C#은 마이크로소프트가 개발한 객체지향 언어입니다. C, C++과 문법이 비슷하면서도 고수준의 추상화된 문법을 제공하다보니 기능이 풍부하고 생산성이 높은 면이 있습니다.  
.Net 플랫폼 위에서 CLR이라는 공통 언어 실행환경이라는 가상환경 위에서 실행이 됩니다. 원래는 윈도우 위주의 개발 환경을 제공하였지만 
.Net Core라는 크로스플랫폼 개발이 진행되어 현재는 리눅스에서도 문제 없이 잘 돌아갑니다.
C#은 컴파일시 IL(중간언어)로 번역된 exe/dll파일이 출력되며, exe파일 실행시 clr 가상환경이 JIT 컴파일러를 통해 실시간으로 네이티브 코드로 번역되며 실행됩니다. 

- 한국의 개발자들한텐 게임 엔진 Unity의 스크립팅 언어로 유명한 편이고 해외에선 웹 서버 프레임워크 ASP.Net이나 GUI 프레임워크 WPF, MAUI쪽으로 많이 쓰이는걸로 알고 있습니다.

# 입력과 출력

## 출력
```c#
namespace csharp
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.OutputEncoding = System.Text.Encoding.UTF8; 
            Console.InputEncoding = System.Text.Encoding.UTF8;

            Console.WriteLine("hello, world!!");
            Console.Write("without linefeed");
            Console.WriteLine($"{1}형식지정자는 나중에 문자열 다룰 때 언급하겠습니다.");
        }
    }
}
```
- C#의 기본적인 콘솔 출력 방법입니다. Write 메서드를 호출하여 콘솔을 통해 출력을 내보냅니다. 
- C#은 콘솔 인코딩이나 출력 글자색을 변경하기 쉽다는 장점이 있습니다. 

## 입력
```c#
namespace csharp
{
    internal class Program
    {
        static void Main(string[] args)
        {
            string? input = Console.ReadLine();
            if(input == null)
            {
                return;
            }

            Console.WriteLine(input);
        }
    }
}
```

- Read 메서드를 통해 콘솔 입력을 받습니다. C#과 같은 고수준 언어들은 항상 입력이 null이 될 경우를 생각하고 대응하는게 정석입니다.
