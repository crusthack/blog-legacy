# C# 개요
- C#은 마이크로소프트가 개발한 객체지향 언어입니다. C, C++과 문법이 비슷하면서도 고수준의 추상화된 문법을 제공하다보니 기능이 풍부하고 생산성이 높은 면이 있습니다.
- .Net 플랫폼 위에서 CLR이라는 공통 언어 실행환경이라는 가상환경 위에서 실행이 됩니다. 원래는 윈도우 위주의 개발 환경을 제공하였지만 
.Net Core라는 크로스플랫폼 개발이 진행되어 현재는 리눅스에서도 문제 없이 잘 돌아갑니다.
- C#은 컴파일시 IL(중간언어)로 번역된 exe/dll파일이 출력되며, exe파일 실행시 CLR 가상환경이 JIT 컴파일러를 통해 실시간으로 네이티브 코드로 번역되며 실행됩니다. 
- 한국의 개발자들한텐 게임 엔진 Unity의 스크립팅 언어로 유명한 편이고 해외에선 웹 서버 프레임워크 ASP.Net이나 GUI 프레임워크 WPF, MAUI쪽으로 많이 쓰이는걸로 알고 있습니다.

## hello, world!!
```csharp
namespace csharp
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Console.OutputEncoding = System.Text.Encoding.UTF8; 
            Console.InputEncoding = System.Text.Encoding.UTF8;

            var name = Console.ReadLine();
            Console.WriteLine($"Hello, {name}!!");
        }
    }
}
```

# 예약어, 키워드
[msdn C# 키워드](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/)

## 타입 
- **각종 타입**: `bool`, `char`, `string`, `object`
- **정수형**: `byte`, `sbyte`, `short`, `ushort`, `int`, `uint`, `long`, `ulong`, `nint`, `nuint`
- **실수형**: `float`, `double`, `decimal`
- **기타 타입**: `void`, `dynamic`
- **값, 참조 정의 타입**: `record`, `struct`, `enum`, `class`, `interface`, `delegate`

## 수정자(Modifiers)
- **접근제한자**: `public`, `protected`, `internal`, `private`, `file`
- **클래스 관련**: `abstract`, `sealed`, `static`, `partial`
- **멤버 관련**: `const`, `readonly`, `event`, `volatile`, `async`, `unsafe`, `virtual`, `override`, `new`, `required`, `init`, `scoped`
- **기타**: `extern`, `in`, `out` (공변성/반공변성 한정자)

## Statement
- **조건문**: `if`, `else`, `switch`, `case`, `default`, `when`
- **반복문**: `do`, `for`, `foreach`, `while`, `in`
- **흐름 제어**: `break`, `continue`, `goto`, `return`, `yield`
- **예외 처리**: `throw`, `try`, `catch`, `finally`
- **데이터 무결성**: `checked`, `unchecked`
- **메모리/동기화**: `fixed`, `lock`, `stackalloc`

## Method & Parameter
- **매개변수 제어**: `ref`, `out`, `in`, `params`, `scoped`, `args`
- **호출 규약**: `managed`, `unmanaged` (함수 포인터 관련)

## Namespace
- **범위 및 참조**: `namespace`, `using`, `global`, `static`, `alias`

## Generic & Constraints
- **제약 조건**: `where`, `new`, `notnull`, `unmanaged`, `allows` (C# 13 ref struct 제약 등)

## Access & Operators
- **참조**: `base`, `this`, `nameof`
- **연산자 키워드**: `as`, `is`, `new`, `sizeof`, `typeof`, `operator`, `explicit`, `implicit`, `with`

## Literal
- **값 리터럴**: `null`, `true`, `false`, `default`

## Contextual keywords
- **속성 및 이벤트**: `add`, `remove`, `get`, `set`, `init`, `field`, `value`
- **LINQ (Query)**: `from`, `select`, `where`, `group`, `into`, `orderby`, `join`, `let`, `on`, `equals`, `ascending`, `descending`, `by`
- **비동기**: `async`, `await`
- **패턴 매칭 및 논리**: `and`, `or`, `not`, `when`
- **기타**: `partial`, `extension`, `file`
