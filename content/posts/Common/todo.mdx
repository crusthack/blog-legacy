WebSocket 백엔드는 충전소 식별자를 사용하여 세션을 고유하게 연결하
지만 동일한 세션 식별자를 사용하여 여러 엔드포인트를 연결할 수 있습니
다. 이 구현을 통해 예측 가능한 세션 식별자가 생성
=> 충전소 서버와 충전소 웹소켓 세션 연결. 정상적인 구조면 인증 절차를 통해 예측 불가능한 세션을 수립해야 하는데,
충전소마다 매번 고정된 세션 값(식별자)을 사용하여 세션을 수립. 이 때문에 제 3자가 손쉬운 세션 탈취가 가능해짐

세션 하이재킹 또는 섀도잉이 가능
여기서 가장 최근의 연결은 합법적인 충전 스테이션을 대체하고 해당 스테이션을 위한 백엔드 명령을 수신합니다
=> 각 충전소별 세션 식별자를 탈취하면 기존 충전소-서버 간의 연결을 끊어버리고 새로운 연결을 강제로 수립하는게 가능해짐

권한이 없는 사용자가 다른 사용자로 인증을 받거나 악의적인 행위자가 
유효한 세션 요청으로 백엔드를 압도하여 서비스 거부 조건을 유발할 수 있습니다
=> 정상적인 세션을 훔쳐 사용하거나, 다른 사람의 통신을 방해해 서비스 가용성에 지장을 만들 수 있음
