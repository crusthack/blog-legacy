다. 이 구현을 통해 예측 가능한 세션 식별자가 생성
=> 충전소 서버와 충전소 웹소켓 세션 연결. 정상적인 구조면 인증 절차를 통해 예측 불가능한 세션을 수립해야 하는데,
충전소마다 매번 고정된 세션 값(식별자)을 사용하여 세션을 수립. 이 때문에 제 3자가 손쉬운 세션 탈취가 가능해짐

세션 하이재킹 또는 섀도잉이 가능

=> 각 충전소별 세션 식별자를 탈취하면 기존 충전소-서버 간의 연결을 끊어버리고 새로운 연결을 강제로 수립하는게 가능해짐
