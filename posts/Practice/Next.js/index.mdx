# Next.js 개요
- 웹 페이지 렌더링 작업과 서버사이드 데이터 처리를 한 번에 할 수 있도록 도와주는 풀스택 프레임워크
- 정적 페이지로 빌드하여 빠른 페이지 배포가 가능하도록 도와줌, 동적 데이터 처리가 필요한 부분은 데이터 패치를 통해 사용 가능 
- 기존 리액트 웹사이트는 클라이언트 사이드에서 단일 페이지로 실시간 렌더링 되기 때문에, 속도상의 단점과 검색 엔진 사용에서의 불리함 존재  
    서버사이드 렌더링과 정적 페이지 생성을 통해 웹페이지 로딩 속도와 검색 엔진 최적화 개선
