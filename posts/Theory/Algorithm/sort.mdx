# 정렬 개요
- 정렬은 자료구조 안의 원소들은 가중치에 따라 순서대로 꺼내올 수 있도록 교체하는 행위
- 기본적으로 오름차순(숫자가 커지는 순서)로 정렬되는게 일반적이며, 필요에 따라 내림차순(숫자가 작아지는 순) 혹은 여러가지 멤버를 가진 클래스 객체의 경우\
문자열의 길이, 숫자 비교 이후 문자열 비교 같은 복합적인 방식으로 우선순위(가중치)에 따라 정렬이 가능합니다.
- 정렬은 기본적으로 모든 원소들을 순회하면서 값 비교를 통한 교체(swap) 과정을 거칩니다. 
- 컨테이너 순회 방식이 어떻게 되는지에 따라 시간 효율이 결정됩니다.
- 기본적으로 배열(벡터)를 정렬하는 예제를 통해 정렬을 설명합니다.

# Bubble Sort O(N^2)
- 자료구조를 순회하면서 지속적으로 연속된 2개 원소를 비교하면서 교체를 수행하는 행위를 n번 수행합니다.
- n길이의 컨테이너를 0번째부터 n-1번째 원소까지의 순회, 이후 n-2번째까지 원소까지의 순회...\
이를 n번 수행함으로써 궁극적으로 순회를 (n + 1) * n / 2 번 하게되는 정렬 방식입니다. 
- 지속적으로 큰 값이 원소가 지속적인 교체를 통해 하나씩 뒤로 정렬되는 동작을 수행해,\
거품이 수면위로 올라오듯이 큰 원소가 맨 뒤로 정렬된다고 해, 거품 정렬이라고 합니다.
- 정렬을 빠르게 끝낸다면, 만약 1회 순회시 교체한 원소가 있는지 확인하는 플래그값을 설정한다면, 해당 플래그값을 확인해\
컨테이너가 정렬돼있는지를 확인하여 정렬을 그만두는 동작을 통해 살짝 더 빠르게 정렬 수행이 가능합니다.

## 예제 코드
```c++
int* bubble_sort(int* arr, int length)
{
    for(int n = length; n > 0; --n)
    {
        for(int m = 0; m < n - 1; ++m)
        {
            if(arr[m] > arr[m+1])
            {
                swap(arr[m], arr[m+1]);
            }
        }
    }

    return arr;
}
```

## 정리
- 아주 기본적인 정렬 알고리즘입니다. 당장에 정렬 알고리즘을 간단히 구현하라는 명령이 있을 시 대부분의 사람들이 버블 정렬을 구현합니다.
- 다만 기본적으로 다른 O(N^2) 정렬들에 비해서도, 매번 swap을 수행하는 비용에 따른 단점이 큽니다.


# Selection Sort O(N^2)
- 선택정렬은 자료구조를 순회하며 가장 큰 값 하나를 찾은 뒤 맨 뒤의 원소와 교체하는 동작을 수행합니다.
- 버블정렬과 비슷한 방식의 순회를 수행하지만, 한 차례의 순회가 끝난 후에야 교체를 수행한다는 이점이 존재합니다.
- N^2 정렬중 그나마 빠른 속도를 일반적으로 선보입니다.

## 예제 코드 
```c++
int* selection_sort(int* arr, int length)
{
    for(int n = length; n > 1; --n)
    {
        int target_index = 0;
        for(int m = 1; m < n; ++m)
        {
            if(arr[target_index] < arr[m])
            {
                target_index = m;
            }
        }
        swap(arr[target_index], arr[n - 1]);
    }

    return arr;
}
```

# Insertion Sort O(N^2)
- 삽입정렬은 컨테이너의 앞 부분부터 하나씩 범위를 늘려, 이미 정렬된 부분을 늘려나가는 정렬입니다.
- 정렬이 된 부분의 바로 뒤 원소를 하나씩 포함시키며, 해당 원소를 이미 정렬이 된 부분에서 알맞은 위치로 한 칸씩 앞당기며 정렬을 수행합니다.
- 거품 정렬보다는 살짝 빠르지만, 삽입 정렬이 일반적으로 더 빠릅니다.

## 코드 예제
```c++
int* insertion_sort(int* arr, int length)
{
    for(int n = 1; n < length; ++n)
    {
        for(int m = n; m > 0; --m)
        {
            if(arr[m] < arr[m-1])
            {
                swap(arr[m], arr[m-1]);
            }
            else
            {
                break;
            }
        }
    }

    return arr;
}
```
# Heap Sort O(N log N)
- 부모노드와 자식노드 2개가 존재한다는 이진 트리 노드를 구조를 사용하여, 부모 노드가 자식 노드보다 작거나 크다는 조건만을 유지하도록 합니다.
- 배열구조에서 자식 노드는 부모 노드의 인덱스 n값의 2n+1과 2n+2로 정의됩니다. 
##### 오름차순 정렬 방법
1. 최대 힙 배열 정렬. 힙 배열상으로 높이 1인 부모 노드부터 시작해서 높이 n인 부모노드 들에 대해 힙 순서상의 정렬 수행 O(N)
2. 맨 앞의 루트 노드 원소와 맨 뒤의 원소를 교체 수행 후 범위 하나씩 줄이기. O(N log N)
- O(N) + O(N log N) => O(N log N)
