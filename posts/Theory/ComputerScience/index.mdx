# Math, Physics
- 이산수학, 선형대수, 미적분학, 확률통계

- 컴퓨터 공학에 대한 생각
- 컴퓨터를 사용하여 유용한 산출물을 만들어내는 것
- 컴퓨터에게 명령을 내림으로써 유의미한 output을 뽑아내는 것, 보통 문제를 푼다고 함 
- output이란 일반 애플리케이션일 수도, 다시 컴퓨터에게 명령을 잘 내리기 위한 유틸리티일 수도 있음 
- 명령을 내리는 것 -> 코딩, 산출물 -> 애플리케이션 
- 작성된 프로그램으로써 말을 하며 프로그램이 보여주는 출력을 통해 증명 수행 
- AI에 의한 메타 변화? 없음. 컴퓨터(AI)에게 명령을 내림으로써 애플리케이션을 제작하는 것엔 변화가 없음. 

- 하드웨어: 물리적인 기계장치. 수학과 물리적 이론을 토대로 일반 공학계열, 전자공학이 컴퓨터 기기를 설계 및 구현 
- 소프트웨어: 기계장치가 저장하고 있는 전압 정보, 0과1 로 이루어진 데이터. 하드웨어가 소프트웨어를 순차적으로 읽어들이며 기계 동작을 수행 
- 컴퓨터공학은 이 소프트웨어를 잘 만듦으로써 하드웨어가 동작을 수행하도록 명령을 내림 

- 코딩 - 컴퓨터 명령을 모아둔 코드를 작성하는 행위  
    기본적으로 단순히 에디터를 통해 코드(영어 문장)을 작성하는 행위에 지나지 않음
- 프로그래밍 - 컴퓨터 애플리케이션을 제작하는 행위  
    제작할 애플리케이션에 대한 전체적인 구조 설계, 실행 환경 고려, 보안 설계 등이 종합적으로 요구됨 

- 컴퓨터 계층은 저수준부터 고수준으로 나뉨. 저수준일수록 하드웨어 컴퓨터에 가까워지며 고수준으로 올라갈수록 컴퓨터 동작이 추상화됨 
- 물리, 수학적 동작 원리를 바탕으로 한 계층
- 논리회로, 컴퓨터구조를 비롯한 컴퓨터 하드웨어 구조 
- 운영체제, 네트워크
- 컴파일러, 가상머신, 실행환경, 알고리즘, 자료구조,
- 프로그래밍
