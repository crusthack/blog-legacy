블로그 개선 방향성
1. 관리자(나) 로그인. 내 개인 포스터들 관리 가능 
2. 서버 사이드 동작 포스트, 슬라이드 변경 내용 저장. 메모랑 그리기 요소 다 같이 저장
3. 포스트 삭제, 등록, 수정 
4. 게스트 유저들이 마음대로 마크다운 포스트 작성할 수 있는 자유게시판. IP로 식별 
5. pdf 올리고서 각 pdf 페이지별로 슬라이드 관리할 수 있는(메모, 그리기) 기능 추가 및 저장 가능 
6. 권한 설정. 최고 관리자: 초염몽. 관리자: 파이숭이. 게스트 및 일반유저:불꽃숭이.
7. 포스트 읽기, 쓰기(수정) 권한. 
- 아마존 ec2-user에 올림. nginx, next.js, asp.net core
- DB는 기본적으로 SQLite 사용 
- 기본적인 목적. vs code 환경을 벗어난. 포스트 관리 
- 현재는 a 컴퓨터에서 작업하다가 b컴퓨터로 넘어가면 버전관리 귀찮은 문제가 존재 

포스트 종류:
내가 작성한 포스트 / 일반 유저가 작성한 포스트 
일반 유저가 작성한 포스트는 포스트에 걸린 비밀번호를 통해 소유권 주장 

a. 읽기 시나리오 
todo 같은 개인 포스트 진입 - 로그인 확인 후 super user 아니면 reject
비공개 포스트 진입 - 코드 입력 혹은 super user 열람 가능 
일반 포스트 진입 - 아무나 열람 가능

b. 수정 시나리오 
superuser는 개인 포스트 전체 수정 가능
일반 유저는 자신이 작성한 포스트만 수정 가능(비밀번호 확인)

c. 삭제 시나리오 
superuser는 전체 포스트 삭제 가능 
admin은 일반 포스트 삭제 가능 
일반 유저는 비밀번호를 통한 소유권 인증 후 포스트 삭제

기본적으로 모든 포스트 정보는 백엔드 측에서 관리 
캐싱을 위해 Next.js가 일정 주기로 static generate수행 

메모나 그리기 내용은, super user의 포스트에서만 저장 
일반 포스트는 단순 mark down 텍스트만 저장 
일단은 보안이나 강건성을 위해, mdx는 제외. mark down형식만 지원
