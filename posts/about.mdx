# 소개
>소켓 프로그래밍을 기반으로 컴퓨터 네트워크에 대한 공부를 주로 하였습니다.\
>Windows 환경에서의 애플리케이션 개발에 관심이 있어 Win32 API, DirectX에 대한 학습을 하였습니다.\
>생산성이 좋은 C#을 사용하여 .NET 환경에서의 개발을 선호합니다.\
>Next.js를 활용한 정적 웹 사이트를 기반 웹 개발을 공부하고 있습니다.

# 관심 분야
- 윈도우 시스템 프로그래밍, 윈도우 애플리케이션 개발
- 컴퓨터 네트워크 및 네트워크 보안
- 웹 브라우저

# 기술

    - DirectX
